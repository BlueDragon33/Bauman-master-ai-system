# L7-B1 · Russian coverage audit

This step is a read-only coverage gate for the existing Russian specialist
engine. It does not project Russian lessons into Universal Lesson V2, change
the Russian runtime, rewrite source content or write learner state.

## Coverage boundary

The audit follows four learner-facing capability tiers:

1. preparatory: Vietnam A0–A2 plus the STANKIN preparatory stage;
2. technical: Bauman semesters 1–2, technical lectures, AI/ASOIU and reports;
3. academic: semester 3, НИР, literature, seminar and scientific argument;
4. defense: semester 4, ВКР structure, presentation and committee questions.

Raw item volume is not treated as proof of learning quality. B1 verifies only
structural coverage, exact legacy mapping, support-family presence and source
integrity. Pedagogical depth, duplicate-template quality and evidence mapping
remain explicit review work in L7-B2–B9 and the new Learning Quality round.

## Protected invariants

- Keep all 26 Russian lesson IDs and Russian titles.
- Keep the six-stage `vn → prep → hk1 → hk2 → hk3 → hk4` order.
- Keep dialogue, speaking, handwriting, flashcard, assessment and simulation
  sources owned by the Russian specialist engine.
- Keep official code `09.04.01` distinct from personalized display
  `09.04.01/11`.
- Do not infer mastery from lesson count, slide count or question count.

The machine-readable evidence is generated by
`scripts/academic/l7-b1-russian-coverage-audit.cjs`.
