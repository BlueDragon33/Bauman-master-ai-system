# MAIN CANVA V1 · Round 1 Design System

## Đã làm

1. Kiểm kê cấu trúc Main: index, CSS, JS, PlanningBridge.
2. Thêm scope `body.canva-main-v1` để áp dụng giao diện mới mà không phá logic cũ.
3. Dựng design system Canva-inspired: nền gradient sáng, card bo lớn, border nhẹ, shadow mềm, button/pill/input/menu đồng bộ.
4. Làm lớp override an toàn cho sidebar, topbar, auth, hero, KPI, panel, modal, toast.
5. Thêm responsive guard cho desktop/tablet/mobile.

## Ghi chú Canva

Canva connector không có design trực tiếp phù hợp; Brand Template bị giới hạn Canva paid plan. Vì vậy round 1 áp dụng trực tiếp tinh thần Canva vào CSS nội bộ.
