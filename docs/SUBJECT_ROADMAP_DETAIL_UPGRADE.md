# Nâng cấp lộ trình trong môn học

Bản này bổ sung lộ trình chi tiết trong từng Subject: mục tiêu giai đoạn, thống kê module/bài học/giờ học, chi tiết từng module, kế hoạch học theo ca, bài học, mô phỏng, bài tập, kiểm tra, tiêu chí đạt và liên kết Bauman/luận văn.

Các file đã cập nhật:
- `subjects/*/data/curriculum.json`
- `subjects/*/assets/*.js`
- `subjects/*/assets/*.css`

Mở bằng VS Code + Live Server tại `index.html`.
