## Dữ liệu
- `curriculum.json`: lộ trình 12 module GĐ1
- `lessons.json`: bài học chi tiết
- `formulas.json`: kho công thức

- `tests.json`: kiểm tra theo mức Dễ/Trung bình/Khá/Giỏi
- `knowledge-index.json`: chỉ mục tìm kiếm cho trợ lý môn
