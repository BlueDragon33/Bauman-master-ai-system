# Main PlanningBridge V3 QA Checklist

- [ ] Mở Main bằng VS Code Live Server.
- [ ] Vào Lịch học, mở một ca Tiếng Nga.
- [ ] Mission gửi xuống môn có `protocol=BAUMAN_PLANNING_BRIDGE_V3_ROUTE_CARDS`.
- [ ] Nếu môn cảnh báo thiếu thời lượng, Main hiện ⚠ trên Tổng quan và ô lịch.
- [ ] Bấm `Tạo lại lịch`, Main bổ sung ca học thường và gửi lại mission.
- [ ] Bấm `Học bù thêm giờ`, Main ưu tiên cuối tuần để sửa lỗi/học bù.
- [ ] Main không tự ép cuối tuần là kiểm tra, chỉ gửi tín hiệu cuối tuần.
- [ ] Nếu môn gửi route cards, ô lịch hiển thị nút dẫn tới nơi học.
