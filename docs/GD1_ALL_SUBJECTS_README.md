# GĐ1 · Các môn chương trình con đã bổ sung

Đã thêm các Subject còn lại cho Giai đoạn 1 theo kiến trúc Subject-owned data:

- `subjects/programming/` · Python, CSDL và kỹ nghệ phần mềm cho hệ thống AI
- `subjects/ai/` · Machine Learning, Neural Systems và đánh giá mô hình nhập môn
- `subjects/systems/` · АСОИУ/АСОИУ, hệ tự hành và độ tin cậy hệ thống
- `subjects/signal/` · Xử lý tín hiệu, chuỗi thời gian, telemetry và cảm biến
- `subjects/research/` · Phương pháp nghiên cứu, НИР và luận văn ВКР

Mỗi môn có:

```text
index.html
editor.html
subject-manifest.json
subject-manifest.js
assets/<subject>.css
assets/<subject>.js
data/curriculum.json
data/lessons.json
data/formulas.json
data/exercises.json
data/tests.json
data/knowledge-index.json
```

Main đã được trỏ đường dẫn tự động trong `assets/js/main.js`.
