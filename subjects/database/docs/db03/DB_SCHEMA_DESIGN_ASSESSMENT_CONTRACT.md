# DB Schema Design Assessment Contract

Grade separately:
1. entity/relation selection;
2. attribute/domain choices;
3. candidate/primary/composite keys;
4. foreign keys/cardinality;
5. integrity constraints;
6. mapping from requirements;
7. explanation/trade-offs.

Different schemas may be valid under different explicit assumptions. Do not reject a valid alternative merely because it differs from the exemplar.

ER-to-relational tasks assess cardinality, optionality, mapping, key propagation, relationship attributes and integrity constraints.

Strong evidence includes an invalid state prevented by a chosen constraint.
