# DB Normalization Assessment Contract

Grade independently:
- FDs;
- candidate key where required;
- current normal-form violation;
- decomposition;
- target normal form;
- lossless join if required;
- dependency preservation if required.

Alternative decompositions pass when they satisfy the stated properties.

Remediation routes errors to keys/FDs, 2NF, 3NF, BCNF or decomposition-property prerequisites.

Do not award normalization points for unsupported claims that more normalization always means faster.
