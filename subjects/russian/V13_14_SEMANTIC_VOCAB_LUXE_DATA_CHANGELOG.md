# V13.14 Semantic Vocab + Luxe Data

- Từ vựng: đổi nhóm chi tiết thành `Nghĩa · Ý nghĩa · Ứng dụng`.
- `Ý nghĩa` giải thích vai trò/ngụ ý giao tiếp hoặc học thuật của từ/cụm.
- `Ứng dụng` giải thích môi trường sử dụng: lớp học, ký túc xá, giáo vụ, metro, столовая, phòng lab, v.v.
- Tab Dữ liệu: tinh gọn bố cục, đổi ngôn ngữ thô `Kho đạn` thành `Kho dữ liệu`, làm lại hero, nhóm, file card, preview card theo hướng sáng và sang hơn.
- Giao diện: thêm nhóm nền sáng trong modal Giao diện, đổi nút Giao diện sang kiểu sáng.
