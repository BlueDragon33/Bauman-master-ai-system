# External data source backup

Thư mục này giữ các gói JSON nguồn/tổng hợp trước đây để đối chiếu hoặc tái sinh dữ liệu.

Runtime của môn Tiếng Nga không đọc trực tiếp thư mục này. Khi chạy học thật, chương trình đọc từ:

`subjects/russian/data/`

Không xóa thư mục này nếu còn cần kiểm tra nguồn dữ liệu hoặc sinh lại vocab/speaking/test bank.
