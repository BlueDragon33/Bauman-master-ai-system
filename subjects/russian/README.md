## Current learning direction

Early-stage priority:

`HEAR → IMITATE/SHADOW → SPEAK → PRINT → CURSIVE → SOUND↔LETTER → VISUAL/CONTEXT MEANING → READ → WRITE → DIALOGUE`

This is a priority loop, not a rigid one-pass curriculum. Listening and speaking remain active throughout later stages.

## Vocabulary meaning

Vocabulary learning surfaces must not use Vietnamese translation as the answer.

Preferred meaning channels:

- image/illustration;
- pictogram;
- scene;
- action/gesture;
- contrast;
- category/examples;
- audio;
- situational context;
- later, simple Russian definition.

Vietnamese remains allowed for navigation, operational help, and safety instructions. English is not the default semantic bridge.

## Cyrillic literacy

All 33 letters must be covered through:

- uppercase/lowercase print recognition;
- print ↔ cursive recognition;
- sound association;
- confusable-letter practice;
- tracing and free writing;
- reading in real words.

The current cursive system is render-based. Browser/package visual-difference proof is an explicit Turn 23 obligation and is required before final freeze.
