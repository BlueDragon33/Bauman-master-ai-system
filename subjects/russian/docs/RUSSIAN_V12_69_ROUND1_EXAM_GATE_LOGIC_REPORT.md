# V12.69 Round 1 Exam Gate Logic

## Scope
- Added learning-day based exam unlock gate.
- Day < 7: weekly exam locked.
- Day 7: unlock 7-day exam and easy level only.
- Day 14: unlock 14-day exam and medium.
- Day 21: unlock hard.
- Day 28: unlock 28-day exam and all levels.
- After day 28, route reset and full exam reset are locked until all required papers pass >= 8.0/10.

## Notes
- Per-paper reset remains available so a failed paper can be redone.
- Full route reset and full exam reset are blocked when week 4 is incomplete/not passed.
- Dropdown options now show locked cycles/levels as disabled.
