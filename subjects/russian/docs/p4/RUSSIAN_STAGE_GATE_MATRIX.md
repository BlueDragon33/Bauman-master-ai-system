# Russian P4 Stage Gate Matrix

Stage gates evaluate critical competencies. They do **not** simply average all available quiz percentages.

| Stage | Gate | Critical capability evidence | Recognition quiz role | Pass rule |
|---|---|---|---|---|
| Foundation | Survival simulation | navigate survival chain; handle transport/dorm/administration/daily-life interaction | supporting evidence | must include successful interaction/performance evidence |
| Prep | Classroom + academic task | follow instruction, read task, ask clarification, explain method | supporting evidence | critical classroom/academic competencies cannot be compensated by unrelated quiz score |
| HK1 | Lecture comprehension + explanation | understand mini lecture, take notes, reconstruct/explain | supporting evidence | listening + explanation evidence required |
| HK2 | Technical report | describe technical concept/problem/data/result | supporting evidence | technical production evidence required |
| HK3 / НИР | НИР presentation + Q&A | 3–5 minute research report and unscripted question response | supporting evidence | presentation + interaction/argument evidence required |
| HK4 / ВКР | Integrated defense | read/listen/note/explain/present/defend in a new technical scenario | supporting evidence | integrated performance + defense Q&A required |

## Gate invariants

- Required competencies are explicit.
- Critical evidence cannot be replaced by an unrelated high average.
- A 20/40/60/100-question paper may support a gate but cannot by itself prove speaking/writing/transfer/performance.
- Gate history is keyed by stable gate ID and transaction ID.
- Repeated write with the same transaction ID is idempotent.
- AI feedback or route navigation cannot unlock a gate.
