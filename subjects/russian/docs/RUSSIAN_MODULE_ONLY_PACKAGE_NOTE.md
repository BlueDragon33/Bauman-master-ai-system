# Russian Bauman Module Only · Main-ready package

Gói này chỉ chứa module môn Tiếng Nga trong `subjects/russian/`, không kèm Main.

Cách dùng với Main:

1. Giải nén ZIP.
2. Copy thư mục `subjects/russian/` vào thư mục Main tương ứng.
3. Mở Main bằng Live Server.
4. Main gọi module qua:
   - `subjects/russian/index.html`
   - `subjects/russian/editor.html`

Module đã tự chứa dữ liệu trong:

- `subjects/russian/data/`
- `subjects/russian/external-data/`

Không cần copy thêm dữ liệu ngoài.
