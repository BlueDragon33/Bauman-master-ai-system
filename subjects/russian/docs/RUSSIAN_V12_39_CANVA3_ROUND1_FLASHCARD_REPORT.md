# Russian Bauman V12.39 · Canva 3 Round 1 UX Flashcard

## Phạm vi lượt 1
- Áp tinh thần Canva phương án 3 vào giao diện: nền sáng, mint/blue, card mềm, bóng đổ nhẹ, nút bo tròn.
- Sửa tab Từ vựng/Flashcard theo yêu cầu: thẻ chính lớn hơn, bảng nghĩa bên phải thu gọn.

## Sửa Flashcard
1. Bố cục desk chuyển sang ưu tiên thẻ chính khoảng 65%, bảng nghĩa khoảng 35%.
2. Chữ Nga dài tự phân loại độ dài (`term-normal`, `term-long`, `term-xlong`, `term-xxlong`) để co cỡ chữ và xuống dòng.
3. Bảng nghĩa chuyển thành rail dọc gọn, ít chiếm ngang.
4. Giữ giải nghĩa Việt/Anh ở giai đoạn Việt Nam.

## QA kỹ thuật
- Cần mở Live Server để soi thực tế visual trên nhiều kích thước màn hình.
