P8 does not claim that every university specialty term is complete. It establishes a canonical, provenance-aware minimum technical layer consumed by R11–R21.

| Domain | Canonical coverage | Primary targets |
|---|---:|---|
| Mathematics | equation, variable, function, derivative, integral, vector, matrix, probability, optimization, constraint | R14 |
| Computer science | algorithm, input data, data structure, complexity, process, memory, OS, network, database/query/API | R14, R17 |
| AI/ML | dataset, feature, model, training, validation, loss, accuracy, inference, neural network, overfitting | R15, R17 |
| Database | database, DBMS, schema, internal schema | R14, R17 |
| Networks / OS | computer network, backbone network, RTOS, dispatcher | R14, R17 |
| Control / automation | control object, feedback, controller/PID, signal, sensor, actuator, stability, transfer function, state, process interfacing | R14, R17 |

| Experiment / report | experiment, obtained results, accuracy, error | R16, R17 |
| Academic discourse | 15 reusable functions | R12, R14, R16–R21 |

## Authority rule
- `VERIFIED`: term is backed by an identified normative terminology source.
- `SOURCE_ASSERTED`: term is already present in the canonical R11–R21 curriculum or a named domain source but P8 does not overclaim a normative definition.
- No external fact may be promoted merely because it is common technical vocabulary.
