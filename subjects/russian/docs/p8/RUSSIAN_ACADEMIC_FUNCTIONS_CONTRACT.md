# Russian P8 Academic Functions Contract

Academic functions are **language actions**, not mastery scores and not a second lesson engine.

Each function must have:
- stable ID;
- Russian functional label;
- learner-facing Vietnamese meaning;
- reusable Russian patterns;
- one or more R11–R21 target lesson IDs.

P8 functions support definition, exemplification, conditions, problem formulation, algorithm description, data/trend description, result reporting, conclusion, citation, research gaps, clarification, polite disagreement, academic email and research framing.

P9 may consume these functions when building reading/writing/НИР/ВКР production tasks. P9 must not duplicate them as a second canonical owner.
