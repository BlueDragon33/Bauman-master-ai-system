# Russian P9 Reading Progression Contract

Progression:
sign/form/message -> notice/email -> article/textbook -> technical instruction/documentation -> abstract -> paper fragment -> research material -> defense evidence.

Operations must include more than translation:
locate, infer, classify, extract, outline, compare, summarize, explain, reconstruct, synthesize and transfer.

The canonical task inventory is `data/reading.json`. Tasks reference P8 AcademicFunction/TechnicalConcept IDs and target R11-R26. Text bodies may be attached later only through P7 provenance/authority rules.
