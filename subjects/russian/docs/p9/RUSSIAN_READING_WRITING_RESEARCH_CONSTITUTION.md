# Russian P9 Reading · Writing · НИР · ВКР Constitution

## Mission
Turn P8 technical/academic input into learner-produced research output without creating a second assessment engine.

## Canonical boundaries
- ReadingText -> `data/reading.json`.
- WritingTask -> existing `data/writing.json`.
- PerformanceTask -> `data/performance-tasks.json`.
- AcademicFunction -> P8 owner.
- TechnicalConcept -> P8 owner.
- Official scoring/mastery -> P4 only.
- Linguistic authority -> P7 only.

## Production ladder
technical input -> locate/extract -> notes -> outline -> summary -> paraphrase -> technical explanation -> lab/report -> research synthesis -> НИР -> ВКР -> defense Q&A.

## Integrity rules
1. Reading is not translation-only.
2. Handwriting is not equivalent to written production.
3. Model text may support learning but cannot be copied as evidence of mastery.
4. P9 task completion does not itself write mastery.
5. P9 consumes P7/P8 canonical facts by ID; it does not fork them.
6. Research output must make objective, method, evidence/result, interpretation, limitation and conclusion distinguishable when the task requires them.
7. Citation/source practice must preserve provenance; P9 does not invent sources.

## Exit
Learner journeys can move from technical input to research output for R11-R26 while P4 remains assessment authority.
