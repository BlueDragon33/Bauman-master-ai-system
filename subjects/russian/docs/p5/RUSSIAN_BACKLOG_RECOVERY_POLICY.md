# Russian P5 Backlog Recovery Policy
A large backlog must not freeze the UI or consume the whole day.

- Planner caps input slices and output count.
- Vocabulary remains scheduled by `vocab-srs.js`; P5 consumes only due summaries.
- Cross-skill review remains owned by `learning-state.js`.
- New learning is never permanently blocked by backlog.
- Productive skills retain balance anchors.
- No rich optional dataset is loaded merely to render Today.
- Learner may manually browse outside the plan.
