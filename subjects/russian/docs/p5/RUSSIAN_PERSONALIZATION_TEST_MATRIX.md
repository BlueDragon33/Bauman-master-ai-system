|---|---|
| New learner | balanced starter plan; no fake mastery |
| Strong learner | no unnecessary remediation |
| Weak speaking | weakness/skill-balance speaking task surfaces |
| Weak grammar | repair task routes to grammar/review |
| Huge backlog | bounded output; no full-dataset scan |
| No backlog | continue path + balanced productive tasks |
| Short session | capped plan remains useful |
| Intensive mode | capacity increases without changing truth |
| Offline | planner uses local P4/review/SRS state |
| Unsupported speech API | priority not corrupted |
| Stage transition | stage read from canonical runtime |
| Manual browsing | remains possible |
| Determinism | same state/version => same ordered plan |
| Duplicate signals | one task id => one plan item |
| Render safety | build/render does not write P4 mastery |
