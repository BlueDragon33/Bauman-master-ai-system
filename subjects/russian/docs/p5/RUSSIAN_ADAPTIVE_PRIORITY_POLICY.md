# Russian P5 Adaptive Priority Policy
Priority is evidence-first, deterministic and bounded.

1. Explicit unexpired manual override.
2. Cross-skill due review.
3. Vocabulary due SRS.
4. P4 weakness repair.
5. Resume/continue path.
6. Skill-balance anchors.

Multiple reasons for one canonical item must not duplicate the task. Priority never writes mastery. Backlog does not grant higher truth status; it only affects scheduling pressure.
