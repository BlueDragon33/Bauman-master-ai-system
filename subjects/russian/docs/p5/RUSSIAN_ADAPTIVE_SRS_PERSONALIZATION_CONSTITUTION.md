# Russian P5 Adaptive SRS & Personalization Constitution

Phase: **P5 — Adaptive SRS & Personalization**

## Mission
Personalize the path without personalizing truth. P5 chooses the next highest-value learning action from trustworthy P4 evidence while preserving canonical curriculum, learner agency and state integrity.

## Canonical ownership
- `assessment-mastery.js`: authoritative attempt/evidence/mastery truth.
- `vocab-srs.js`: per-vocabulary-card scheduling.
- `learning-state.js`: cross-skill review queue and resume state.
- `adaptive-planner.js`: **single canonical Today/recommendation planner**.
- Presentation renders recommendations but never owns priority truth or mastery.

## Rules
1. Planner is read-only toward P4 mastery and assessment.
2. Opening/rendering Today must not mark tasks complete.
3. Same inputs + same algorithmVersion produce the same plan.
4. Due review, weakness repair, current path and skill balance coexist.
5. Listening, speaking, writing and technical production cannot be starved by vocabulary backlog.
6. AI is optional and non-authoritative.
7. Intensive mode changes capacity, not curriculum truth.
8. Manual overrides are explicit, scoped and expirable.
9. Recommendation reasons are learner-visible.
10. Manual browsing remains available.

## Priority order
Manual override → due cross-skill review → due vocabulary → assessed weakness → continue path → skill-balance anchors.

## Production effect
No production publish authority. P5 remains a foundation phase; publish belongs to P17.
