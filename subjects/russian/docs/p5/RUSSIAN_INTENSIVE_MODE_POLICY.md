# Russian P5 Intensive Mode Policy
Intensive mode is temporary scheduling pressure, not a new curriculum.

- normal default max plan: 8 items;
- intensive default max plan: 12 items;
- stage/mastery truth remains unchanged;
- no automatic permanent level jump;
- manual overrides should include reason/scope/expiry when used;
- returning to normal mode preserves P4 mastery/SRS.
