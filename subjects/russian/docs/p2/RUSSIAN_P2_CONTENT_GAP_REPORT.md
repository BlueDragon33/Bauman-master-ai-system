## Structural gaps to close in later implementation

1. R03 target needs a dedicated numbers/time/date/money responsibility.
2. Foundation responsibilities currently jump early into Math/lecture material; that material should be preserved and re-homed into R10/R12/R14 rather than discarded.
3. R08/R09 target must explicitly own six-case use plus tense/aspect/motion progression.
4. R12 target must own mathematical/formal Russian, while lecture survival belongs to R14.
5. R15–R18 need clearer separation of CS/software, DB/data/AI, control/automation and experiment/report.
6. R22 must become full НИР production rather than only terminology for novelty/contribution/limits.
7. R26 must become an integrated capstone with transfer and unexpected Q&A, not only a broad academic-language review.
8. The current 8,000-word vocabulary scale is not itself mastery depth; P3/P7 must add authoritative lexical structure without fabricating unverified fields.

## Preserve list

Do not destroy:
- stable R01–R26 identities;
- useful current lesson slides/examples;
- basic speaking / dialogue / deep-speaking separation;
- offline large-data architecture;
- handwriting authority;
- existing source datasets.
