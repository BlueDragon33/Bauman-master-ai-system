# Russian Subject — Listen, Speak, Literacy & Visual Semantics

This is the responsibility map for the Russian subject learning experience.

The learning system must build Russian meaning directly through sound, action, visual context, letter recognition, reading and writing. Vietnamese may remain in application navigation or safety/help instructions where necessary, but it must not be the semantic answer on vocabulary learning surfaces.

## Pedagogy order

The early learning loop is:

```text
HEAR CONTEXT
   ↓
IMITATE / SHADOW
   ↓
SPEAK
   ↓
RECOGNIZE PRINT
   ↓
RECOGNIZE CURSIVE
   ↓
CONNECT SOUND ↔ LETTER
   ↓
UNDERSTAND THROUGH VISUAL / ACTION / SCENE
   ↓
READ CHUNKS
   ↓
TRACE / WRITE
   ↓
USE IN DIALOGUE
```

The order is a priority rule, not a rigid one-time pipeline. Listening and speaking repeat throughout every stage.

## Vocabulary semantic rule

Vocabulary learning surfaces must not reveal Vietnamese translations as the meaning.

Meaning should be established through one or more of:

- photo or illustration;
- pictogram;
- scene;
- action/gesture;
- object relation;
- contrast pair;
- category/example set;
- simplified Russian explanation after the learner is ready;
- audio + situational cue.

English is not the default semantic bridge either.

Legacy translation fields may remain in source data temporarily for migration compatibility, but they are not learner-facing semantic authority.

## Cyrillic literacy rule

The learner must master all 33 Russian letters across:

- uppercase print;
- lowercase print;
- uppercase handwriting/cursive;
- lowercase handwriting/cursive;
- sound association;
- visual confusables;
- recognition from print → cursive and cursive → print;
- tracing;
- free writing;
- reading inside real words.

Unicode identity alone is not proof of handwriting distinction. A cursive visual style or explicit shape/asset must be verified in the rendered experience.

## Grammar rule

Grammar is downstream of heard and spoken patterns.

The beginner flow is:

`heard pattern → spoken pattern → noticed contrast → tiny rule → immediate reuse`.

Grammar must not displace listening/speaking time in the Vietnam orientation stage.

## Authority boundaries

This subject layer owns:

- Russian pedagogy;
- Russian content presentation;
- speaking/listening flow;
- literacy flow;
- visual vocabulary semantics;
- subject-local review evidence.

It does not own:

- Hub routing authority;
- Device Access Gate;
- global academic scheduler authority;
- Foundation registry mutation;
- cross-subject identity contracts.

Protected contracts remain protected, including `BAUMAN_SUBJECT_BRIDGE_V1` and existing learner-state persistence until separately migrated.
