# V13.23 · Storage + Learning Structure Menu Polish

## Thay đổi chính
- Tab Dữ liệu/Lưu trữ:
  - Nút **Kho dữ liệu** giữ tiêu đề ở dòng chính.
  - Trạng thái nhóm đang chọn được đưa xuống dòng phụ, không hiển thị cùng hàng gây phình bảng.
  - Khi ở toàn bộ kho, không hiển thị nhãn phụ kiểu “Tất cả nguồn”.
- Tab Học tập:
  - Gom 5 nút **Lý thuyết / Bài tập / Nghe/Nói / Ôn tập / Kiểm tra** vào một menu xổ dọc.
  - Tạo nút 3D nổi **Cấu trúc bài học**, nhấn vào sổ dọc 5 lựa chọn.
  - Thêm indicator neon bên cạnh để biểu thị tab hiện hành; nút **Cấu trúc bài học** luôn giữ nguyên tên.

## Kiểm tra
- Đã kiểm tra cú pháp JavaScript bằng `node --check`.
- Không thay đổi dữ liệu JSON, không đổi logic lọc nguồn dữ liệu, không đổi logic chuyển tab học tập.
