# PROBLEM

Problem is distinct from desired solution.

# OPPORTUNITY

Potential for value creation/capture under uncertainty.
Must be supported, not merely asserted.

# CUSTOMER SEGMENT

Explicit group with relevant shared need/context.

# USER VS BUYER

Separate where actual business model requires it.

# CUSTOMER NEED

Evidence-based need/pain/job/outcome according actual terminology.

# ALTERNATIVE

What customer currently does instead.

# COMPETITOR

Direct/indirect alternatives supported by evidence.

# VALUE PROPOSITION

Why target customer should prefer solution under defined context.

# SOLUTION HYPOTHESIS

A proposed way to deliver value, not yet validated truth.

# BUSINESS MODEL

Technology-neutral model of value creation, delivery and capture using actual course framework.

# KEY ASSUMPTION

Uncertain proposition whose falsity would materially affect viability.

# EXPERIMENT

Designed test of assumption.

# EXPERIMENT RESULT

Observed result + method/sample/context.

# EVIDENCE ITEM

Interview, survey, observation, usage, payment, pilot, source, experiment, etc.

# MARKET DEFINITION

Customer + geography/context + need/category/timeframe as relevant.

# MARKET SIZE ESTIMATE

Method + sources + assumptions + uncertainty.

# TAM/SAM/SOM

Only if course supports.
Definitions explicit; SOM is not guaranteed sales.

# PRICING HYPOTHESIS

Price/metric/package + target segment + evidence.

# REVENUE MODEL

How money/value is captured, if relevant.

# COST ITEM

Fixed/variable/direct/other actual taxonomy.

# UNIT ECONOMICS

Only activate actual course metrics.
Formula and assumptions explicit.

# FINANCIAL SCENARIO

Projection based on explicit assumptions, not prediction certainty.

# TRACTION EVIDENCE

Observed behavior/outcome with provenance.

# CHANNEL / PARTNER

Only actual scope.

# BUSINESS RISK

Assumption/market/economic/execution/regulatory categories only if supported.

# DECISION

Possible:
proceed,
iterate,
pivot,
pause,
stop,
other actual terminology.

Every substantive pitch claim links to evidence/assumption.
