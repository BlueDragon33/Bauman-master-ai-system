# 0. PURPOSE

This package defines the subject architecture for the Bauman IU5 course:

**Предпринимательство — Entrepreneurship**

The subject is treated as evidence-based entrepreneurial decision making, not as motivational startup content.

High-level chain:

`Problem / Need`
→ `Customer / Stakeholder`
→ `Value Proposition`
→ `Market / Context`
→ `Solution Hypothesis`
→ `Business Model`
→ `Experiment`
→ `Evidence`
→ `Revenue / Cost Logic`
→ `Unit Economics`
→ `Risk`
→ `Go / Iterate / Stop`
→ `Growth / Operations`
→ `Entrepreneurial Evidence`.

Shared constitutions:

- C1 — Extensible Platform Architecture
- C2 — Future Professional UI/UX
- C3 — Professional QA + Auto-Fix
- C4 — Real Learning & Outcome System

**This README is the single execution runbook.**

No separate execution cheat sheet is required.

# 11. STEP 4 — ENT04

`ENT04_MARKET_EXPERIMENT_FINANCE_AI.md`.

Goal:

**provide market/evidence/experiment/economic reasoning tools without inventing market reality.**

Potential capabilities:

- customer/problem evidence registry;
- interview/observation synthesis;
- competitor/alternative map;
- market-sizing calculator if supported;
- pricing/revenue scenario;
- cost-structure model;
- unit-economics calculator;
- break-even/cash-flow basics if supported;
- experiment tracker;
- assumption/risk register;
- traction dashboard;
- pitch/business-case builder;
- AI Entrepreneurship Tutor.

Rules:

- survey intent ≠ purchase behavior;
- market-size estimate ≠ guaranteed revenue;
- TAM ≠ obtainable market automatically;
- competitor absence ≠ market opportunity automatically;
- revenue ≠ profit;
- profit ≠ cash flow;
- growth ≠ sustainable economics;
- AI cannot fabricate customers, interviews, revenue, costs, traction, funding or market size.
