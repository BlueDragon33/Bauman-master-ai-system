# ENT03 — OPPORTUNITY · CUSTOMER · BUSINESS MODEL · ASSESSMENT

Mode:

`PROBLEM-FIRST · EVIDENCE-SKEPTICAL · MULTIPLE-VALID-MODEL-AWARE`

# ENTRY

Requires ENT02.

# REASONING LOOP

Problem
→ customer/segment
→ evidence
→ current alternative
→ value proposition
→ key assumptions
→ business model
→ experiment
→ observed result
→ economic implication
→ risk
→ decision.

# ASSESSMENT DIMENSIONS

Grade separately:
- problem framing;
- customer/segment;
- evidence quality;
- alternative/competitor reasoning;
- value proposition;
- assumption identification;
- experiment quality;
- business-model coherence;
- market reasoning;
- pricing/economics where supported;
- traction;
- risk;
- decision.

# IDEA VS OPPORTUNITY

A technically interesting idea is not automatically an entrepreneurial opportunity.

# CUSTOMER SEGMENT

Reject:
“everyone”,
“all businesses”,
“all students”
unless course case genuinely supports broad market and evidence.

# CUSTOMER EVIDENCE

Distinguish:
opinion,
stated intent,
observed behavior,
payment,
retention,
contract/pilot,
other evidence types.

Do not create a universal ranking if syllabus does not.

# SURVEY OVERCLAIM

Stated purchase intention is not actual purchase behavior.

# VALUE PROPOSITION

Must connect customer need + solution benefit + alternative.

# COMPETITOR / ALTERNATIVE

“No competitor” requires strong evidence and may indicate no market/poor research.

# KEY ASSUMPTION

Learner identifies most consequential uncertainties.

# EXPERIMENT

Tests an assumption with:
method,
metric,
criterion,
decision consequence.

# VANITY METRIC

Raw signups/views/downloads may be insufficient without business context.

# MARKET SIZE

If in scope:
method/source/assumptions must be shown.

# TOP-DOWN / BOTTOM-UP

Only if course supports.

# TAM / SAM / SOM

Do not accept category totals as obtainable revenue.

# PRICING

If in scope:
price decision requires customer/value/cost/context evidence.

# REVENUE VS PROFIT

Known misconception fixture.

# PROFIT VS CASH FLOW

If financial scope supports.

# UNIT ECONOMICS

Formula semantics explicit.

# LTV / CAC

Only if actual syllabus supports.
Do not accept invented acquisition/retention assumptions.

# BREAK-EVEN

Only if scope:
inputs and assumptions traceable.

# TRACTION

Evidence must be actual observed outcome.

# GROWTH

Growth can coexist with poor economics.

# PIVOT / ITERATE

Decision is response to evidence, not failure stigma.

# MULTIPLE VALID BUSINESS MODELS

Different viable models may exist.
Grade coherence/evidence rather than one canvas.

# HINT LADDER

H1 state problem  
H2 narrow customer  
H3 identify evidence  
H4 inspect alternatives/value proposition  
H5 identify critical assumption  
H6 design experiment  
H7 inspect economics/risk  
H8 make evidence-grounded decision

# TEST-OF-TESTS

Known invalid reasoning must fail:
- “people liked it” = validated business;
- no competitors because no search was done;
- TAM = first-year revenue;
- 100 survey respondents = proven demand;
- revenue growth = profitability;
- unit economics use inconsistent units/time periods;
- pitch traction number has no source.
