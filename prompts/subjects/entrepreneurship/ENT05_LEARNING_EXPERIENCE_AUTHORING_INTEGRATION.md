# VALUE PROPOSITION UX

# ASSUMPTION MAP

Highlight:
importance,
uncertainty,
test status,
evidence.

# EXPERIMENT BOARD

Show:
hypothesis,
method,
metric,
threshold,
result,
decision.

# MARKET SIZING UX

If in scope:
method/source/assumptions shown next to result.

# ECONOMICS UX

Revenue/cost/unit-economics values must expose formula and units.

# TRACTION UX

Observed vs projected clearly separated.

# PITCH BUILDER

Claims link to evidence.
Unsupported claims visibly flagged.

# AI TUTOR UX

Advisory.
Never inserts fabricated market/customer metrics.
