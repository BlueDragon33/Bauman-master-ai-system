# 0. PURPOSE

This package defines the subject architecture for the Bauman IU5 course:

**Управление проектированием информационных систем — Management of Information Systems Design**

The subject focuses on managing the design effort that transforms a need into a coordinated, reviewable, deliverable information-system design.

The high-level chain is:

`Need / Business Context`
→ `Project / Design Objective`
→ `Scope`
→ `Stakeholders`
→ `Deliverables`
→ `Design Breakdown`
→ `Dependencies`
→ `Plan / Milestones`
→ `Resources / Responsibilities`
→ `Risk / Change`
→ `Design Reviews`
→ `Acceptance`
→ `Handoff`
→ `Lessons / Evidence`.

Shared constitutions:

- C1 — Extensible Platform Architecture
- C2 — Future Professional UI/UX
- C3 — Professional QA + Auto-Fix
- C4 — Real Learning & Outcome System

**This README is the single execution runbook.**

No separate execution cheat sheet is required.
