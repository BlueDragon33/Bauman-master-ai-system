# AI AUTHORITY BOUNDARY

AI cannot:
- approve scope;
- approve change;
- accept deliverable;
- close review;
- invent schedule/cost/effort;
- declare project complete.

# AI GROUNDING

Canonical project state + actual evidence + learner attempt.

# GOLDEN FIXTURES

At minimum:
- scope creep;
- deliverable rejected after tasks closed;
- invalid dependency;
- stale status;
- unowned critical deliverable;
- baseline change;
- risk/issue distinction;
- AI completion refusal.

# PASS

PASS when project state is evidence-derived and AI cannot become management/approval authority.

# FINAL PRINCIPLE

**STATUS SHOULD BE COMPUTED FROM EVIDENCE WHERE POSSIBLE, NOT INVENTED TO MAKE A PROJECT LOOK HEALTHY.**
