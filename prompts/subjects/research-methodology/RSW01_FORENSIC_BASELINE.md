# RSW01 — FORENSIC BASELINE
## Audit current Research Methodology / Scientific Work reality before redesign

Mode:

`AUDIT-ONLY · NO-REDESIGN · REPOSITORY-TRUTH-FIRST`

# MISSION

Map actual methodology, literature, experiment, writing, citation, reproducibility and NIR-related content.

# DISCOVERY

Search for:
- methodology;
- scientific method;
- research question;
- hypothesis;
- research gap;
- literature review;
- source search;
- bibliography;
- citations;
- DOI;
- experiment;
- study design;
- variables;
- sampling;
- control/comparison;
- reproducibility;
- research notebook;
- research report;
- paper;
- peer review;
- plagiarism;
- research ethics;
- NIR;
- VKR;
- thesis;
- conference;
- AI research assistant.

Do not assume all are in scope.

# COURSE / CONTENT INVENTORY

Record:
- lessons;
- concepts;
- source;
- tasks;
- templates;
- assessments;
- downstream links.

# RESEARCH QUESTION AUDIT

Check:
- specificity;
- answerability;
- scope;
- variables/phenomena;
- population/context/time when relevant.

# OBJECTIVE / TASK AUDIT

Find whether objective/tasks are distinct from question.

# HYPOTHESIS AUDIT

Check:
- testability;
- variables;
- direction where relevant;
- evidence criteria.

# GAP AUDIT

Determine whether “gap” is evidenced by literature rather than asserted.

# SOURCE / LITERATURE AUDIT

Map:
- search tools;
- source types;
- metadata;
- DOI/identifier;
- full-text access;
- source annotations;
- citation records.

# SOURCE QUALITY AUDIT

Check whether course distinguishes:
- primary;
- secondary;
- review;
- textbook;
- documentation;
- preprint;
- peer-reviewed work;
- nonacademic source.

Do not impose one rigid hierarchy across all research questions.

# CITATION AUDIT

Find:
- citation style;
- bibliography generator;
- reference metadata;
- in-text citation;
- missing-source checks.

# FABRICATED-CITATION RISK

Critical:
AI/authoring must not produce unverifiable references as real.

# LITERATURE REVIEW AUDIT

Check:
- synthesis;
- comparison;
- contradiction;
- gap;
- chronology/theme/method organization.

# CLAIM-EVIDENCE AUDIT

Find how claims link to evidence/source/result.

# METHOD AUDIT

Inventory actual:
- experiment;
- observational study;
- simulation;
- modeling;
- computational experiment;
- case study;
- survey;
- comparative analysis;
- other.

Only evidence-supported methods.

# VARIABLE / CONSTRUCT AUDIT

Check definitions and operationalization.

# SAMPLING AUDIT

If relevant:
population,
sample,
selection,
sample size,
bias.

# EXPERIMENT AUDIT

Check:
- protocol;
- control/baseline;
- randomization/blinding if relevant;
- repeated trials;
- stopping rules;
- parameter settings.

# CONFOUNDING / BIAS AUDIT

Find whether explicitly taught.

# STATISTICAL AUDIT

Map use of:
- estimation;
- hypothesis tests;
- confidence intervals;
- effect size;
- multiple comparisons;
- power.

Actual scope only.

# EXPLORATORY / CONFIRMATORY AUDIT

If present, check separation.

# REPRODUCIBILITY AUDIT

Find:
- software version;
- dependency lock;
- seed;
- dataset version;
- code revision;
- parameter/config;
- hardware;
- environment.

# REPLICABILITY AUDIT

Check whether distinct from reproducibility.

# DATA / ARTIFACT PROVENANCE AUDIT

Record:
- source;
- license;
- checksum/version;
- transformation history;
- ownership/privacy.

# RESEARCH LOG AUDIT

Find notebooks/lab logs/change records.

# FIGURE / TABLE AUDIT

Check:
- source data;
- labels;
- units;
- caption;
- statistical/error representation;
- reproducibility.

# SCIENTIFIC WRITING AUDIT

Map:
- abstract;
- introduction;
- methods;
- results;
- discussion;
- conclusion;
- limitations;
- references.

Do not assume IMRaD if actual scope differs.

# RUSSIAN LANGUAGE BOUNDARY

Separate research methodology from Academic Russian language instruction.

# ETHICS AUDIT

Find:
- consent;
- privacy;
- human/animal research;
- conflicts;
- fabrication/falsification;
- plagiarism;
- responsible AI use.

Only apply relevant ethics domains.

# AI AUDIT

Check whether AI:
- fabricates citations;
- invents evidence;
- rewrites hypotheses post hoc;
- produces unsupported conclusions;
- generates fake peer review;
- writes official mastery.

# NIR / VKR OVERLAP

Map current content that later belongs to dedicated NIR/VKR integration.

# ASSESSMENT AUDIT

Classify:
- question formulation;
- literature synthesis;
- method choice;
- protocol;
- evidence evaluation;
- analysis;
- critique;
- report;
- peer review.

# GRADER AUDIT

Check exact-template overfitting.
Multiple scientifically valid methods may exist.

# AUTHORING AUDIT

Find how instructors create research tasks/rubrics/source packs.

# DUPLICATE OWNER

Find duplicate:
- citation store;
- source registry;
- research artifact store;
- experiment log;
- evidence graph;
- AI research assistant;
- report rubric.

# LEGACY

KEEP / MIGRATE / RETIRE / UNKNOWN.

# RISK REGISTER

At minimum:
- fabricated citation;
- unsupported claim;
- vague question;
- method/question mismatch;
- p-value overclaim;
- causal overclaim;
- missing provenance;
- irreproducible experiment;
- plagiarism/attribution risk;
- AI evidence fabrication;
- duplicate research record.
