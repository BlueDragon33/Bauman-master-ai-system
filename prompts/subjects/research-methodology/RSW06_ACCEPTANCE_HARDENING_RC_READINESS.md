# RSW06 — ACCEPTANCE · HARDENING · LEGACY CLOSURE · RC READINESS

Mode:

`SOURCE-RED-TEAMED · CLAIM-EVIDENCE-REGRESSION · REPRODUCIBILITY-TESTED · NO-KNOWN-BLOCKER`

# MISSION

Prove Research Methodology & Scientific Work is epistemically sound, source-safe, reproducible, accessible and exact-RC ready.

# GATES

A canonical research truth
B reasoning/assessment
C source/evidence/reproducibility
D AI/ethics
E UX/a11y/offline/performance/security
F legacy/RC.

# QUESTION MATRIX

Test:
- too broad;
- non-answerable;
- leading;
- conclusion embedded;
- feasible/scoped;
- legitimate descriptive/exploratory question.

# GAP MATRIX

Reject unsupported “research gap” assertions.

# METHOD FIT

Known mismatched designs must fail appropriate rubric.

# HYPOTHESIS

Do not require when methodology legitimately does not need one.

# OPERATIONALIZATION

Known vague construct without measurement/observation definition must be flagged where relevant.

# SAMPLING / BIAS

Known selection-bias fixture.

# CONFOUNDING

Known causal-confounding fixture.

# CAUSAL CLAIM

Correlation-only evidence cannot support causal wording without additional design/assumptions.

# SOURCE VERIFICATION

Test:
- real metadata;
- invalid DOI;
- title/author mismatch;
- fabricated source;
- duplicate source;
- abstract-only limitation.

# SOURCE SUPPORT

Citation must actually support nearby claim.

# PRIMARY / SECONDARY

Known misclassification fixture.

# CITATION FORMAT

Formatting errors separate from source-existence/source-support errors.

# PLAGIARISM / ATTRIBUTION

Test:
- verbatim unattributed copy;
- close paraphrase without citation;
- reused code/data without attribution where required.

# CLAIM-EVIDENCE

Known:
- evidence too weak;
- sample too narrow;
- claim too broad;
- result vs interpretation confusion.

# STATISTICAL CLAIMS

If in scope:
- p-value overclaim;
- statistical vs practical significance;
- confidence interval misuse;
- multiple-comparison issue;
- null-result overclaim.

# EXPLORATORY / CONFIRMATORY

If supported:
known post-hoc hypothesis masquerading as pre-specified must be flagged.

# CHERRY-PICKING

Known result-selection fixture where scope supports.

# REPRODUCIBILITY MATRIX

Check:
- data version;
- code version;
- dependency/environment;
- seed;
- config;
- command/procedure;
- artifact output.

# REPRODUCTION RUN

A small computational experiment should reproduce within expected tolerances/context.

# REPLICABILITY LANGUAGE

Do not claim independent replication from same-team rerun.

# FIGURE / TABLE PROVENANCE

Known mismatch fixture.

# NEGATIVE RESULTS

System must allow valid negative/null results without forcing “success”.

# ETHICS

Relevant scenarios:
- privacy;
- consent;
- fabrication/falsification;
- conflict;
- attribution;
- AI disclosure.

Do not invent institutional requirements not in course/policy.

# AI ACCEPTANCE

AI must:
- never fabricate citation/DOI;
- never fabricate participants/data/results;
- distinguish source summary from its own inference;
- avoid causal overclaim;
- preserve limitations;
- not write official mastery;
- not label its advisory review as real peer review.

# PROMPT-INJECTION / SOURCE SECURITY

Malicious instructions embedded in source documents must not override research task/policy.

# COPYRIGHT

Source-pack use respects allowed excerpts/licensing.
Do not duplicate full protected papers without rights.

# HIDDEN MATERIAL

Protected answer keys/source annotations unavailable to learner/AI when required.

# OFFLINE

Actual supported source/artifact cache verified.

# PERFORMANCE

Measure:
subject load,
source list,
claim-evidence graph,
research log,
citation rendering,
authoring.

# RESPONSIVE / A11Y

Research canvas, source lists, evidence matrix, citations and peer review usable on mobile/tablet/desktop.

# AUTHORING ACCEPTANCE

Author creates:
- question task;
- source critique;
- method task;
- protocol;
- reproducibility task;
- peer-review task

without app-code edits for ordinary cases.

# LEGACY

Resolve duplicate:
- source registry;
- citation store;
- evidence graph;
- research artifact store;
- experiment log;
- AI research helper;
- old route/flag.

# FOUNDATION OWNER GATE

No duplicate statistics/ML/domain truth.
No duplicated Academic Russian owner.
NIR/VKR orchestration remains downstream.

# MIGRATION

If canonical IDs/schema change:
aliases,
source/reference migration,
artifact migration,
learner evidence preservation,
rollback.

# RC FREEZE

Freeze:
SHA,
content snapshot,
subject pack,
verified source-pack revisions,
tool/provider profile,
config,
lockfile.

# PRODUCTION SMOKE PROFILE

1. open Research Methodology subject;
2. open one canonical research-question lesson;
3. create/inspect one question + method;
4. open one verified source;
5. link one claim to evidence;
6. run one reproducibility checklist/example;
7. verify active subject pack/source revision;
8. verify citation/source provider status;
9. verify optional AI grounded/fallback;
10. offline cached metadata/artifact if supported.

# BLOCKERS

- fabricated citation accepted as real;
- claim without required evidence accepted;
- systematic causal overclaim;
- irreproducible canonical experiment;
- AI fabricates data/result/source;
- protected/private research data leaks;
- duplicate canonical research owner;
- migration corrupts source/evidence records.
