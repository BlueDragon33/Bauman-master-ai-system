# RSW03 — SCIENTIFIC REASONING · METHOD SELECTION · CRITIQUE · ASSESSMENT

Mode:

`CLAIM-EVIDENCE-FIRST · METHOD-QUESTION-MATCHED · MULTIPLE-VALID-METHOD-AWARE`

# ENTRY

Requires RSW02.

# REASONING LOOP

Context
→ problem
→ gap
→ question
→ objective/hypothesis
→ variables/constructs
→ method/design
→ protocol
→ evidence
→ analysis
→ result
→ claim
→ limitation
→ reproducibility
→ communication.

# ASSESSMENT DIMENSIONS

Grade separately:
- problem/gap;
- research question;
- hypothesis/objectives;
- operationalization;
- method selection;
- protocol;
- evidence quality;
- analysis;
- claim support;
- uncertainty/limitations;
- provenance/citation;
- reproducibility;
- ethics;
- scientific communication.

# QUESTION QUALITY

Detect:
- too broad;
- trivial;
- unanswerable;
- value-laden without operationalization;
- conclusion embedded in question.

# GAP QUALITY

Gap must be supported by literature/evidence.

# METHOD FIT

A method is good only relative to the question.

# MULTIPLE VALID METHODS

Critical policy:
different scientifically defensible methods may answer the same question.

Grade rationale/trade-offs.

# HYPOTHESIS

If applicable:
variables/expected relation/testability explicit.

# NO-HYPOTHESIS DESIGNS

Do not penalize legitimate descriptive/exploratory/qualitative work for lacking classical hypothesis if course/scope permits.

# OPERATIONALIZATION

Construct → measurable/observable procedure.

# SAMPLING

Assess:
population,
selection,
representativeness,
bias,
sample adequacy where relevant.

# CONTROL / BASELINE

Appropriate comparison needed for certain claims.

# RANDOMIZATION

If relevant:
learner explains what bias it addresses.

# CONFOUNDING

Known causal-overclaim fixture required.

# BIAS

Possible:
selection,
measurement,
survivorship,
publication,
confirmation,
other actual scope.

# EVIDENCE QUALITY

Consider:
source relevance,
method,
sample/data,
recency where relevant,
replication,
limitations.

Do not reduce to journal prestige alone.

# PRIMARY / SECONDARY

Learner distinguishes direct evidence from synthesis.

# SOURCE TRIANGULATION

Where appropriate, use multiple independent sources.

# CLAIM STRENGTH

Claim strength must not exceed evidence/design.

# CORRELATION / CAUSATION

Known invalid causal claim must fail.

# RESULT / INTERPRETATION

Separate observed/analyzed result from interpretation.

# STATISTICAL SIGNIFICANCE

If in scope:
p-value does not quantify effect importance.

# PRACTICAL SIGNIFICANCE

Magnitude/context.

# CONFIDENCE INTERVAL

If in scope:
interpretation must follow actual statistical model.

# NULL RESULT

Avoid “no significant effect therefore no effect exists”.

# MULTIPLE COMPARISONS

If in scope:
familywise/FDR or appropriate correction concepts.

# EXPLORATORY ANALYSIS

Clearly labeled.

# CONFIRMATORY ANALYSIS

Protocol/hypothesis history matters.

# NEGATIVE RESULTS

Can be scientifically valuable.

# REPRODUCIBILITY

Learner provides sufficient artifact/process metadata.

# REPLICABILITY

Learner understands distinction.

# FIGURE / TABLE INTERPRETATION

Must match underlying evidence.

# CITATION

Reference supports the statement actually cited.

# QUOTE / PARAPHRASE

Attribution and source fidelity.

# PLAGIARISM

Known unattributed reuse fixture.

# AI-ASSISTED RESEARCH

Learner must verify AI-provided:
- citation;
- calculation;
- code;
- summary;
- factual statement.

# PEER REVIEW

Assess:
- major claim;
- evidence;
- method;
- reproducibility;
- limitations;
- constructive critique.

# PARTIAL CREDIT

Separate scientific reasoning from prose quality.

# HINT LADDER

H1 clarify research problem
H2 sharpen question
H3 identify evidence needed
H4 choose method/design
H5 inspect bias/confounding
H6 inspect analysis/claim
H7 inspect reproducibility/limitations
H8 full worked example only when allowed.

# TEST-OF-TESTS

Known invalid work must fail:
- fabricated source;
- unsupported gap;
- causal claim from correlation only;
- cherry-picked result;
- p-value as effect size;
- non-significant result as proof of no effect;
- unexplained post-hoc hypothesis;
- unreproducible method;
- unattributed copied text/data/code;
- AI-created fake experiment result.

# AI BOUNDARY

AI may coach research reasoning.
It cannot be accepted as primary evidence merely because it generated an answer.
