# RSW02 — ACADEMIC BLUEPRINT & CANONICAL RESEARCH MODEL

Mode:

`QUESTION-FIRST · CLAIM-TRACEABLE · SOURCE-PROVENANCE · REPRODUCIBILITY-AWARE · CANONICAL-OWNER`

# ENTRY

Requires RSW01.

# MISSION

Define one canonical research ontology consumed by lessons, literature tools, experiment workflows, graders, AI and authoring.

# OUTCOMES

Learner can:
- identify research problem;
- formulate answerable question;
- identify evidence gap;
- define objective/tasks;
- formulate hypothesis/proposition where appropriate;
- operationalize constructs;
- select appropriate method;
- evaluate sources;
- design protocol;
- collect/use evidence;
- analyze responsibly;
- distinguish result from interpretation;
- communicate uncertainty/limitations;
- cite and attribute;
- build reproducible research artifacts;
- critique scientific work.

# RESEARCH PROBLEM

Problem explains why inquiry matters and what is unresolved.

# RESEARCH GAP

Gap must connect to evidence/literature.
“Few studies exist” is not sufficient without source support and relevance.

# RESEARCH QUESTION

Question should be:
- scoped;
- answerable;
- linked to evidence/method;
- not already framed as desired conclusion.

# OBJECTIVE

Objective describes intended knowledge/result.

# RESEARCH TASKS

Operational steps, not synonyms for objectives.

# HYPOTHESIS

Only where method/question supports hypothesis testing.
Qualitative/descriptive research may not require a classical hypothesis.

# TESTABILITY / FALSIFIABILITY

Use where appropriate.
Do not force Popper-style framing onto every research method without context.

# CONSTRUCT

Conceptual property.

# OPERATIONAL DEFINITION

How construct is observed/measured.

# VARIABLE

Role and measurement scale/context explicit where relevant.

# CAUSAL ROLES

Exposure/treatment/outcome/confounder/mediator/etc only if actual scope.

# METHOD

Method chosen to answer question.

# STUDY DESIGN

Possible actual designs:
experiment,
observational,
simulation,
computational experiment,
case study,
survey,
comparative study.

Only activate supported designs.

# CONTROL / BASELINE

Appropriate comparator where needed.

# RANDOMIZATION / BLINDING

Only where relevant and feasible.

# POPULATION / SAMPLE

Explicit when empirical sampling exists.

# SAMPLING BIAS

First-class risk.

# MEASUREMENT

Measurement procedure/unit/instrument/provenance.

# RELIABILITY / VALIDITY OF MEASUREMENT

Only actual scope; do not confuse with system reliability course.

# DATA SOURCE

Primary data, secondary dataset, simulation, generated data, etc.

# LITERATURE SOURCE

Metadata:
title,
authors,
venue,
year,
identifier,
URL/location,
source type,
retrieval date if needed,
verification status.

# SOURCE VERIFICATION

Unverified AI-suggested reference cannot be promoted to canonical literature source.

# DOI

Identifier is metadata, not proof of source quality.

# SOURCE ANNOTATION

Key claim/method/result/limitations/relevance.

# EVIDENCE ITEM

Evidence can reference:
- source;
- data;
- experiment run;
- figure;
- table;
- analysis.

# CLAIM

Every substantive scientific claim should be linked to supporting evidence or marked as hypothesis/speculation.

# RESULT

Direct outcome of analysis/observation.

# INTERPRETATION

Separate from result.

# LIMITATION

First-class, not ceremonial final paragraph.

# CORRELATION / CAUSATION

Causal claim requires appropriate design/assumptions/evidence.

# STATISTICAL SIGNIFICANCE

If used:
does not equal practical significance.

# EFFECT SIZE

If supported, separate magnitude from p-value.

# NULL RESULT

Non-significant result is not automatically proof of no effect.

# MULTIPLE TESTING

Only if actual scope.

# EXPLORATORY / CONFIRMATORY

If supported:
analysis intent/history recorded.

# HARKING-LIKE RISK

If hypothesis changed after results, record as exploratory/post hoc rather than pretending preregistered.

# REPRODUCIBILITY

Record:
code,
data,
versions,
config,
seed,
environment,
procedure.

# REPLICABILITY

Independent repetition by another team/system.
Separate from reproducibility.

# ARTIFACT

May include:
dataset,
code,
notebook,
protocol,
model,
figure,
table,
report,
supplement.

# FIGURE / TABLE

Traceable to source data/analysis.

# CITATION RECORD

Formatting style separate from canonical source metadata.

# PLAGIARISM / ATTRIBUTION

Ideas/text/data/code require proper attribution according policy/context.

# ETHICS

Research constraints first-class.
Only relevant requirements activated.

# AI USE RECORD

Record when AI materially assists:
search,
drafting,
coding,
analysis,
translation,
critique.

AI output is not evidence by default.

# PEER REVIEW

Finding includes:
claim,
evidence,
severity/category,
recommendation,
resolution.

# PROVENANCE

Everything important should answer:
“where did this come from?”
