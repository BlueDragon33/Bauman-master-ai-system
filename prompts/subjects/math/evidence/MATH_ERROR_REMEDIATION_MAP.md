# MATH03 · ERROR → REMEDIATION MAP

Status: ACTIVE

| Error | Evidence threshold | Remediation | Recheck |
|---|---|---|---|
| CONCEPT_MISCONCEPTION | repeated/explicit contradiction | contrast definition/example/non-example | new concept variant |
| PREREQUISITE_GAP | prerequisite evidence weak + target failure | route prerequisite repair | independent target retry |
| WRONG_STRATEGY | valid data extraction but incompatible method | strategy comparison/guiding question | new same-skill problem |
| ALGEBRA_ERROR | invalid symbolic transform | local algebra repair | equivalent transform check |
| ARITHMETIC_ERROR | strategy valid, localized computation error | focused recomputation | same method/new numbers |
| DOMAIN_ERROR | exclusion/assumption lost | restore domain + original-problem verification | domain-preserving variant |
| UNIT_ERROR | value plausible but dimension/unit invalid | dimension/conversion repair | new unit-bearing variant |
| PROOF_GAP | conclusion unsupported | identify missing claim/dependency | rubric recheck |
| UNJUSTIFIED | assertion without reason | require rule/theorem/argument | next-step justification |
| TASK_MISUNDERSTANDING | response schema mismatches request | restate givens/unknown | independent retry |
| UNKNOWN | insufficient evidence | do not diagnose | collect more evidence |

One error does not automatically diagnose a stable misconception. Remediation is root-cause/prerequisite-aware and must not default to “redo whole lesson”.
