# MATH BROWSER / DEVICE / ACCESSIBILITY ACCEPTANCE

Status: RC VALIDATION

Validated representative classes:
- desktop 1440×900;
- tablet 1024×768;
- mobile 390×844;
- Chromium automation in Math/Whole-System gates.

Critical acceptance:
- no page-level horizontal overflow in representative Math journey;
- numeric/expression/domain/unit/proof inputs have keyboard paths and labels;
- core actions do not require drag-only interaction;
- error/degraded states contain text, not color only;
- graph capability returns an accessible textual summary;
- formulas and wide Math content may scroll/reflow inside bounded surfaces;
- focus/keyboard smoke is required in MATH06 browser test.

This is a critical-journey accessibility acceptance, not a claim of full WCAG conformance or exhaustive screen-reader certification.
