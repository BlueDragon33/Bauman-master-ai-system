# MATH RESPONSIVE & ACCESSIBILITY MATRIX

Owner: MATH05 · Status: TESTABLE

| Stress case | Desktop | Tablet | Mobile | Nonvisual/keyboard requirement |
|---|---|---|---|---|
| Long formula | readable display | reflow | internal scroll/reflow | selectable semantic text |
| Matrix | full grid | fit/scroll | internal scroll | textual dimensions/value |
| Problem input | full workspace | stacked | single-column | labels + keyboard submit |
| Proof steps | side-by-side optional | stacked | stacked | ordered semantic steps |
| Graph | bounded panel | responsive | bounded panel | expression + sample/summary |
| Errors | adjacent feedback | adjacent | field-local | not color-only |
| Tool unavailable | persistent state | same | same | readable status text |

Target viewport acceptance includes desktop, tablet and 390×844 mobile without page-level horizontal overflow. No full WCAG claim is made without a dedicated audit.
