# MATH INPUT CONTRACT

Owner: MATH05 · Status: ACTIVE

Supported response controls are selected from the problem schema, not one raw-LaTeX box.

Required baseline:
- numeric input;
- algebraic expression + explicit domain/excluded values;
- quantity + units;
- free/long proof text;
- structured reasoning when a validated problem contract requires it.

Rules:
1. Keyboard completion is mandatory for critical tasks.
2. Inputs have programmatic labels and field-local feedback.
3. Mobile controls remain visible above the virtual keyboard and must not require drag-only interaction.
4. Long expressions/matrices use horizontal internal scrolling/reflow rather than page overflow.
5. Parsed/evaluated expressions go through MATH04 capability boundaries; no `eval`/Function.
6. Response type and MATH03 equivalence policy remain authoritative.
7. Input drafts are learner state; they are not mastery.
