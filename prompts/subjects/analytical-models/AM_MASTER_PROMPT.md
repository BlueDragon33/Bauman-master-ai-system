# 5. NON-NEGOTIABLE MODELING INVARIANTS

- System boundary is explicit.
- Variables have semantic meaning.
- Units/dimensions are explicit where applicable.
- Inputs/outputs/states/parameters are not silently conflated.
- Disturbances/observations are explicit when relevant.
- Assumptions are first-class.
- Initial/boundary conditions are first-class.
- Model class is explicit.
- Equivalent mathematical representations can coexist.
- Solver result is not model validity.
- Numerical agreement at one point is not validation.
- Linearization has a validity region.
- Discretization can change behavior.
- Parameter values have provenance/context.
- AI cannot become canonical model authority.
- Visualization cannot mutate canonical equations.
