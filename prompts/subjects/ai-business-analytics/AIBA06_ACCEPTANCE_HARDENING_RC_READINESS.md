# AIBA06 — ACCEPTANCE · HARDENING · LEGACY CLOSURE · RC READINESS

Mode: `KPI-REGRESSION · DECISION-RED-TEAMED · IMPACT-CLAIM-SKEPTICAL · NO-KNOWN-BLOCKER`

# MISSION
Prove AI in Business Analytics is semantically correct, decision-useful, evidence-traceable, privacy-aware and exact-RC ready.

# GATES
A canonical business truth  
B reasoning/assessment  
C data/model/forecast/scenario  
D dashboard/AI  
E UX/a11y/offline/performance/security  
F legacy/RC.

# KPI MATRIX
Test numerator/denominator, time window, segment, aggregation, units, duplicates, missing/late/stale data.

# AGGREGATION
Include weighted/unweighted mismatch, average-of-averages, and reversal/segment effects where relevant.

# MODEL METRIC VS BUSINESS VALUE
Known fixture where technically better score yields worse cost/decision outcome.

# THRESHOLD MATRIX
Test symmetric/asymmetric cost, capacity constraints, prevalence shift and threshold sensitivity.

# FORECAST TO ACTION
Verify horizon, action lead time, cadence and interval/uncertainty.

# LEAKAGE
Reuse ML and Time Series leakage matrices.

# SEGMENTATION
Test tiny/unstable/non-actionable segments and overinterpretation.

# SCENARIO / CAUSALITY
Conditional scenario must not masquerade as observed causal effect.

# ROI / IMPACT
Reject invented conversion, missing cost base, wrong time period, double counting and direct model-metric-to-revenue conversion.

# DASHBOARD
Canonical KPI semantics, freshness and filter/denominator correctness.

# EXPLANATION
Predictive explanations are not causal effects.

# MONITORING
Verify data, KPI, model/forecast, decision rate and business outcome monitoring.

# AI ACCEPTANCE
AI must ask for objective/KPI, preserve uncertainty, avoid fabricated business figures/ROI/causal effects, protect hidden evaluation and never write official mastery.

# SECURITY / PRIVACY
No unauthorized customer/commercial data exposure. Exports respect masking/permissions.

# AUTHORING ACCEPTANCE
Author creates business case, KPI task, threshold task, scenario, dashboard critique and recommendation task without code edits for ordinary cases.

# LEGACY / OWNER CLOSURE
Resolve duplicate KPI registry, semantic layer, dashboard formula, scenario engine, value calculator, explanation layer and stale routes/flags. No duplicate ML/TS/DB/Research truth owner.

# RC FREEZE
Freeze SHA, content snapshot, subject pack, business-case revisions, KPI registry revision, model/forecast refs, config and lockfile.

# PRODUCTION SMOKE PROFILE
1. open subject;
2. open canonical business case;
3. inspect stakeholder/decision/KPI;
4. load safe data/model evidence;
5. run threshold/cost or scenario task;
6. open dashboard/recommendation;
7. verify active subject pack/KPI revision;
8. verify model/forecast refs;
9. verify AI grounded/fallback;
10. verify offline cached case if supported.

# BLOCKERS
- KPI inconsistency;
- model metric presented as business value;
- fabricated ROI/impact;
- causal overclaim;
- forecast/action timing mismatch;
- hidden evaluation leak;
- sensitive data leak;
- AI fabricated evidence;
- duplicate canonical business owner;
- learner-evidence migration corruption.
