# AIBA05 — LEARNING EXPERIENCE · AUTHORING · PRODUCT INTEGRATION

Mode: `SHARED-DESIGN-SYSTEM · DECISION-TRACEABLE · NO-CODE-FIRST · ACCESSIBLE`

# ENTRY
Requires AIBA02–AIBA04.

# PRIMARY SURFACES
- business problem canvas;
- stakeholder/decision map;
- KPI tree;
- data-source explorer;
- model/forecast evidence panel;
- threshold/cost workspace;
- segment explorer;
- scenario/what-if workspace;
- dashboard;
- explanation panel;
- recommendation builder;
- monitoring panel;
- AI tutor;
- report workspace.

# BUSINESS CANVAS
Keep context, stakeholder, decision, objective, constraints and baseline visible.

# KPI TREE
Show primary/supporting metrics and exact definitions.

# MODEL/FORECAST EVIDENCE
Show model identity, evaluation context, forecast origin/horizon and uncertainty.

# THRESHOLD / COST UX
Interactive threshold, volume, FP/FN/action costs, capacity and expected outcome.

# SCENARIO UX
Base vs changed assumptions explicit.

# DASHBOARD UX
Every KPI card links to its canonical definition and freshness metadata.

# RECOMMENDATION BUILDER
Fields: decision, action, target, timing, evidence, expected impact, uncertainty, constraints and monitoring.

# RESPONSIVE / ACCESSIBILITY
Adapt KPI trees/tables/charts/controls across mobile/tablet/desktop; provide semantic table alternatives and non-color cues.

# AUTHORING
Use shared lifecycle. Support no-code creation of business case, KPI task, threshold/cost task, forecast-to-action task, dashboard critique, scenario task and recommendation/report task.

# VALIDATION
Before review verify KPI references, model/forecast refs, freshness, cost assumptions, hidden evaluation protection and test-of-tests.

# SUBJECT PACK
Package safe business cases, KPI definitions and precomputed analytical evidence. No unauthorized confidential data.
