# RE28 — LEARNER METRICS PROJECTION

Owner: RU04 + C4

Mission: derive meaningful local ability metrics from evidence, not XP.

Core metrics:
- independent semantic comprehension;
- support dependence;
- translation dependence;
- normal/native-speed listening;
- transfer success;
- response latency;
- repair skill;
- pronunciation signal availability vs transcript-only;
- retention/review outcome;
- infrastructure failure rate.

Rules:
- derived, recomputable, non-authoritative;
- no hidden network telemetry;
- no raw audio;
- unknown/provider failure excluded from learner-negative scoring;
- keep skill dimensions separate.

PASS when the same evidence yields deterministic metrics and translation-heavy success scores lower independence than unsupported direct comprehension.
