# RE39 — SPEAKING REFLEX SIGNAL

Owners: RU04 + RU05 + C4

Mission: attach optional speech recognition to conversation turns without overstating pronunciation accuracy.

Rules:
- ASR transcript is a recognition signal only;
- record response latency;
- pronunciationAuthority=false;
- stressAuthority=false;
- microphone/provider failure is infrastructure failure;
- no phoneme mastery, no official score.

PASS when transcript/latency can be captured and provider failure remains non-learner evidence.
