# RE02 — SEMANTIC IMMERSION & ACQUISITION RUNTIME

Canonical owners: RU02 + RU03 + RU05 + RU07 + C4

Mission: make Russian meaning emerge from context, action and repeated experience before dependence on translation or grammar explanation.

---

# 1. CORE LOOP

`PERCEIVE → PREDICT → ACT → SEE CONSEQUENCE → UPDATE MEANING → RESPOND`

Each experience should ask whether the learner can infer and act on meaning, not merely match text pairs.

---

# 2. GROUNDING PRIMITIVES

Support reusable primitives such as:
- object identification;
- person/role identification;
- location;
- direction;
- possession;
- quantity;
- color/shape/size;
- action observation;
- action execution;
- sequence;
- before/after;
- cause/consequence;
- emotion/intent;
- request;
- refusal;
- permission;
- correction;
- choice;
- comparison;
- spatial relation;
- temporal relation.

These primitives are content-neutral runtime capabilities.

---

# 3. MEANING WITHOUT TRANSLATION

Examples:

Russian audio: `Дай мяч.`
Scene: speaker extends hand toward a visible ball.
Learner action: selects/drags ball.
Consequence: character receives ball.

The Engine records demonstrated comprehension of the action-object relation.

It does not need to display “дай = give” by default.

---

# 4. SEMANTIC CONTRAST

Use contrast to disambiguate:
- яблоко / груша;
- большой / маленький;
- открыто / закрыто;
- идёт / бежит;
- на / под / в;
- мой / твой;
- сейчас / потом.

Contrast must be grounded visually or situationally when possible.

---

# 5. CHUNK ACQUISITION

Treat high-frequency expressions as meaningful chunks before forced grammatical decomposition.

Examples:
- Как тебя зовут?
- Я не понимаю.
- Повторите, пожалуйста.
- Можно?
- Мне нужно...
- Где...?
- Сколько стоит?
- Я учусь...

Later, link chunk internals to canonical lexical/grammar entities.

Do not delay useful speech until all grammar is explained.

---

# 6. COMPREHENSIBLE INPUT CONTROLLER

Difficulty should combine:
- known concept ratio;
- new concept count;
- utterance length;
- speech rate;
- acoustic clarity;
- syntactic novelty;
- lexical novelty;
- scene predictability;
- number of distractors;
- memory delay;
- support visibility.

Avoid changing every difficulty dimension at once.

---

# 7. SUPPORT ESCALATION

Default sequence:
S0 no support
S1 replay
S2 focus/highlight
S3 slower replay
S4 gesture/animation
S5 semantic contrast
S6 simplified Russian
S7 known-Russian paraphrase
S8 partial model
S9 explicit explanation
S10 native-language translation

Track the highest support level needed.

Mastery evidence should distinguish independent performance from supported performance.

---

# 8. TRANSLATION DEPENDENCY REDUCTION

The Engine should gradually reduce:
- bilingual labels;
- permanent subtitles;
- pre-exposed transcripts;
- Vietnamese hints;
- grammar-first instructions.

But never remove accessibility accommodations blindly.

---

# 9. PREDICTION

Before revealing the next line/action, sometimes ask the learner to predict:
- which object;
- which action;
- what the person wants;
- likely next phrase;
- expected reply.

Prediction is valuable because fluent comprehension is anticipatory, not purely retrospective.

---

# 10. MEMORY RECONSTRUCTION

Use tasks that require reconstructing meaning after delay:
- hear instruction, then act;
- hear short scene, then choose outcome;
- follow 2-step then 3-step commands;
- recall object location;
- retell gist in Russian at later levels.

---

# 11. GRAMMAR DISCOVERY

Default grammar progression:
`EXPOSURE → RECURRING PATTERN → CONTRAST → EXPECTATION → GUIDED DISCOVERY → LABEL/RULE`

Example:
Маша → вижу Машу
Анна → вижу Анну

After enough examples, invite discovery.

Formal grammar remains available and becomes increasingly important at advanced academic stages.

---

# 12. ERROR TREATMENT

Do not interrupt every fluency attempt.

Classify:
- meaning-blocking;
- target-competency;
- persistent;
- pronunciation-critical;
- register;
- cosmetic.

During free speech, prioritize communication and high-value correction.

During focused form practice, increase correction precision.

---

# 13. NATIVE-SPEED BRIDGE

For the same meaning, content may expose:
1. careful native speech;
2. normal native speech;
3. connected casual speech;
4. speaker variation;
5. mild noise;
6. interruption/repair.

The learner should learn that acoustic surface changes while meaning remains.

---

# 14. RUSSIAN-ONLY EXPLANATION LADDER

At suitable levels, explain Russian through simpler Russian using:
- known synonyms;
- antonyms;
- examples;
- gestures;
- category;
- function;
- scene;
- definition.

Native-language explanation remains an escape hatch, not a forbidden feature.

---

# 15. ACQUISITION SESSION DESIGN

A short session should mix:
- new grounded input;
- immediate comprehension;
- imitation/shadowing;
- controlled response;
- delayed retrieval;
- one variation;
- one transfer;
- review of an older weak concept.

Avoid repetitive mechanical drilling without semantic change.

---

# 16. EXPERIENCE GENERATION RULE

Dynamic generation may vary:
- object;
- speaker;
- location;
- distractors;
- order;
- surface wording;
- speed;
- role.

It must preserve:
- canonical meaning;
- target competency;
- difficulty bounds;
- valid answer envelope.

---

# 17. ACCEPTANCE SIGNALS

RE02 is working when:
- learner can choose/act correctly without translation;
- repeated Russian evokes faster responses;
- support level needed decreases;
- transfer to unseen examples occurs;
- natural-speed comprehension improves;
- grammar patterns are anticipated before explicit naming.

---

# 18. FAILURE MODES TO BLOCK

- translation flashcards disguised as immersion;
- decorative images with no semantic role;
- audio that is always unnaturally slow;
- transcript always visible;
- single exact sentence accepted when many natural replies exist;
- grammar explanation before meaningful exposure by default;
- XP awarded as substitute for competence.

---

# 19. RE02 EXIT GATE

Prove at least one end-to-end immersion slice:
scene
→ Russian stimulus
→ meaningful learner action
→ consequence
→ evidence
→ adaptive support
→ transfer variant

with translation unavailable by default but recoverable through the support ladder.
