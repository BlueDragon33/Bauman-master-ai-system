## Purpose

Russian Engine is an implementation track inside the existing Russian subject. It is NOT:
- a second Russian application;
- a second Russian Master Prompt;
- a second Constitution;
- a second design system;
- a second mastery authority;
- a new mandatory remote API;
- a new provider-specific backend.

It exists to turn the Russian subject into a deep, direct-meaning, speech-first learning system that can scale from one local learner to a commercial multi-user product without rewriting the subject.

## Core learning principle

`RUSSIAN SOUND / SCENE / ACTION → MEANING → RESPONSE`

not

`RUSSIAN → VIETNAMESE TRANSLATION → ANALYSIS → RESPONSE`

Translation is a late scaffold, not the default learning path.

## 100-level principle

The target is support for 100 internal learner levels, not 100 technical code layers.

Levels must be data-driven, evidence-gated, independently versioned, and derived from a multidimensional competency model. A learner may be stronger in listening than speaking; therefore a single number never becomes the sole truth of ability.
