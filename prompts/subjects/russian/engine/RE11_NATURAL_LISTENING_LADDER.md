# RE11 — NATURAL LISTENING LADDER

Canonical owners: RU03 + RU05 + RU04

Mission: bridge educationally clear Russian to real connected native speech without permanent slow-audio dependence.

## Difficulty axes
- rate;
- speaker variation;
- reduction;
- phrase stress;
- predictability;
- noise;
- transcript visibility;
- utterance length;
- turn count;
- memory delay.

Only a bounded subset should change at once.

## Listening modes
- sound contrast;
- grounded command;
- chunk recognition;
- gist;
- detail;
- intent;
- sequence;
- note-taking;
- technical lecture;
- multi-speaker.

## Transcript policy
Hidden first by default where comprehension is being tested.
Reveal only through declared support policy or accessibility override.

## Evidence
Listening evidence records what meaning/details were recovered and which support was used.
Provider/media failure is not learner failure.

## Exit
PASS when the same semantic target can be delivered across a controlled native-speech ladder and the learner model can distinguish independent normal-speed comprehension from supported slow-playback comprehension.
