# RU04 — ASSESSMENT · MASTERY · ADAPTIVE · SRS · REMEDIATION
## Russian learning evidence and next-action logic

Former source responsibility: P4 + P5.

---

# 0. MISSION

Specialize the global Real Learning & Outcome constitution for Russian.

RU04 must preserve:

`EXPOSURE ≠ PROGRESS ≠ PERFORMANCE ≠ MASTERY`.

It owns Russian-specific evidence, review and adaptive semantics.

---

# 1. CONSTITUTION ROUTING

Primary:

- C4: assessment/evidence/mastery/retrieval/retention/adaptive boundaries;
- C3: persistence/idempotency/concurrency/regression;
- C1: storage/event abstractions.

C2 only for learner-facing progress/mastery presentation.

---

# 2. COMPLETION ≠ MASTERY

Keep distinct:

- visited;
- started;
- completed;
- passed;
- demonstrated;
- mastered;
- retained/needs review.

Opening a lesson, scrolling, playing audio or viewing an answer is never sufficient mastery evidence.

---

# 3. RUSSIAN MASTERY DIMENSIONS

Preserve meaningful separation across:

- phonetics;
- listening;
- speaking;
- reading;
- writing;
- vocabulary recognition;
- vocabulary production;
- grammar recognition;
- grammar production;
- interaction;
- academic;
- technical;
- research.

Do not collapse everything into one percentage.

---

# 4. ATTEMPT INTEGRITY

Official attempt should preserve:

- stable attempt ID;
- item/assessment ID;
- content revision;
- mode;
- timestamp;
- response;
- evaluation;
- feedback/support shown;
- first-attempt identity.

Retry appends.

Retry never overwrites first attempt.

---

# 5. PRACTICE VS ASSESSMENT

Practice may use:

- hints;
- immediate feedback;
- explanation;
- retries;
- remediation.

Assessment/exam obeys stricter reveal policy.

Do not mix histories without mode metadata.

---

# 6. EVIDENCE-FIRST

Russian evidence may include:

- retrieval;
- form production;
- listening response;
- spoken response;
- writing;
- dialogue task;
- performance task;
- delayed successful review.

Audio playback or AI conversation duration is not independent mastery evidence.

---

# 7. ERROR → REMEDIATION

Use:

failure
→ classify error
→ check prerequisite
→ targeted explanation/contrast
→ controlled repair
→ retrieval
→ novel example
→ production
→ exit check.

Do not route every failure to “redo whole lesson”.

---

# 8. SRS

One canonical scheduler.

Different semantics for:

- active vocabulary;
- passive/reference vocabulary;
- grammar concepts;
- listening contrasts;
- speaking functions;
- integrated performance reminders.

Do not force every content type through one identical card algorithm.

---

# 9. ACTIVE/PASSIVE VOCAB

Do not make all ~8000 lexical entries active production obligations.

Priority depends on:

- stage;
- domain;
- current course;
- learner need;
- evidence;
- prerequisite importance.

---

# 10. ADAPTIVE PLANNER

Planner may choose:

- due review;
- critical weakness;
- current-stage task;
- prerequisite repair;
- active vocabulary;
- listening/speaking exposure;
- enrichment.

It changes the path, not the truth.

---

# 11. SKILL BALANCE

Prevent large vocabulary backlog from starving:

- listening;
- speaking;
- writing;
- technical/research production

when current stage requires them.

---

# 12. RECOGNITION VS PRODUCTION

If recognition is strong and production weak:

prioritize recall/production/transfer.

If recognition is weak:

return to input/noticing/controlled practice before free production.

---

# 13. SUPPORT FADING

Scaffold progression may move:

full bilingual support
→ reduced support
→ Russian hints
→ keywords
→ independent production.

Support may return after evidence of difficulty.

Hinted success is not automatically equivalent to unaided success.

---

# 14. DAILY PLAN STABILITY

One Today/planner owner.

Plan should not reshuffle on every render.

Recompute from meaningful evidence changes.

Multiple reasons should merge into one canonical task entry.

---

# 15. INTENSIVE MODES

Temporary focus may include:

- pre-departure survival;
- arrival;
- exam;
- seminar;
- НИР;
- ВКР defense.

Temporary priority must not permanently distort mastery/curriculum/SRS history.

---

# 16. OFFLINE / FAILURE

Core planner should function without cloud AI.

If adaptive logic fails:

fallback to canonical sequence + due review.

Corrupt recommendation cache must not reset mastery.

---

# 17. STAGE GATES

Russian gates should combine critical competencies rather than average unrelated scores.

Representative integrated gates:

- survival;
- preparatory classroom/academic task;
- lecture comprehension + explanation;
- technical report;
- НИР presentation/Q&A;
- ВКР-style defense.

RU05/RU06 generate evidence.

RU04 interprets it under C4 authority.

---

# 18. AI BOUNDARY

RU07 AI may:

- explain;
- coach;
- create temporary practice;
- suggest review.

AI may not directly:

- write official score;
- grant mastery;
- become SRS owner;
- unlock stage;
- overwrite first attempt.

---

# 19. REQUIRED OUTPUTS

Maintain:

- Russian attempt/evidence mapping;
- stage-gate matrix;
- error/remediation map;
- SRS specialization;
- adaptive priority policy;
- daily planner contract;
- reason codes;
- migration fixtures;
- regression tests;
- RU05/RU06/RU07 evidence interface.

---

# 20. EXIT GATE

PASS when:

- mastery has one canonical authority;
- completion/mastery remain distinct;
- first attempts are immutable;
- review/SRS has one owner;
- adaptive state does not duplicate mastery;
- planner is explainable/stable;
- skill starvation is prevented;
- offline/fallback works;
- old state migrates without silent reset;
- downstream engines emit compatible evidence.

**PERSONALIZE THE PATH · DO NOT PERSONALIZE THE TRUTH.**
