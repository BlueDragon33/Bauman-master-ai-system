# NON-NEGOTIABLE INVARIANTS

- Asset and security objective are explicit.
- Threat scenario has a target and preconditions.
- Risk is contextual.
- Security requirement is verifiable.
- Every control maps to threat/risk/requirement.
- Least privilege and explicit authorization are preferred.
- Authentication and authorization are distinct.
- Encryption is not a universal control.
- Secure storage, transit and access are distinct concerns.
- Secrets are not committed as ordinary content.
- Security evidence is tied to exact configuration/revision.
- Scanner output is evidence candidate, not final truth.
- Incident/recovery claims require tested procedures where applicable.
- AI cannot fabricate vulnerabilities, exploitability, breaches or approval.

# SAFETY BOUNDARY

This subject is defensive.

Do not create learner workflows that operationalize:
- credential theft;
- malware creation;
- stealth/persistence;
- destructive exploitation;
- bypass/evasion;
- unauthorized real-world access.

Use isolated, prebuilt, non-deployable fixtures for defensive reasoning.

# FINAL PRINCIPLE
