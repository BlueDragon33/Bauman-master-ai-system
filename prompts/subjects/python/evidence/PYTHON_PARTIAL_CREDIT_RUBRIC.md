# PYTHON PARTIAL CREDIT RUBRIC
## Ordinal evidence bands, not fake precision

PYTHON03 defines dimensions and ordinal evidence only. C4/global mastery policy decides whether/how evidence contributes to mastery.

For each applicable dimension use:
- **0 — absent/contradicted**
- **1 — partial with substantial support**
- **2 — mostly correct with limited defect/support**
- **3 — independent and robust for the declared task**.

Dimensions:
1. requirement understanding;
2. decomposition;
3. core logic;
4. edge handling;
5. test quality;
6. debugging/root-cause evidence;
7. clarity/maintainability when relevant;
8. final behavior;
9. reproducibility when relevant;
10. transfer/explanation when relevant.

Not every task uses every dimension. Do not compute a universal weighted percentage from these bands unless an explicit downstream assessment policy authorizes it.

Syntax failure may still preserve evidence of requirement understanding or debugging skill; correct final output may still score weakly on robustness/transfer. Support level must be stored alongside evidence.
