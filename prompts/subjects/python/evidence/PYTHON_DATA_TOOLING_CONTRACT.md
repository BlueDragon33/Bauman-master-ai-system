## Implemented validation scope

The stdlib profile supports declared text inputs for CSV/JSON practice: up to
8 files, 16 KiB total, validated relative names, fresh chrooted workspace.
Traversal, undeclared host paths and arbitrary package installation are denied.
These learner-supplied inputs are untrusted and carry no official provenance.

The lab downloads source text as `practice.py`, not server artifacts. Artifact
collection is empty. External datasets, binary uploads, NumPy/Pandas, databases
and artifact export are unavailable until separately pinned/validated profiles
exist. No adjacent subject theory or learner-state owner is changed.
