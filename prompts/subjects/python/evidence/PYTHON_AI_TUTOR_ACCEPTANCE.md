# PYTHON AI TUTOR ACCEPTANCE

Status: **DEGRADED-SAFE**

Current Python product has an advisory AI contract but no privileged model/provider authority in the execution path.

Accepted:
- AI may explain, hint, debug and review when a provider is present;
- learner code/comments are untrusted input;
- runtime/test evidence outranks AI claims;
- hidden tests/solutions are excluded;
- AI cannot write mastery or official score;
- absence/outage degrades to canonical explanations and deterministic tooling.

This RC does not claim a production AI coding model as required functionality.
