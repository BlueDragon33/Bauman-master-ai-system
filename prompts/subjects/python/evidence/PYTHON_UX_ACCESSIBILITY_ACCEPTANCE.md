# PYTHON UX & ACCESSIBILITY ACCEPTANCE

P6 browser acceptance preserves P5 coverage and adds explicit offline behavior.

Required viewports:
- 1440×900;
- 1024×768;
- 390×844.

Required behavior:
- no page-level horizontal overflow;
- Run/Test/Submit remain distinct;
- editor and stdin have explicit labels;
- status/error text is non-color-only;
- keyboard Run remains available;
- draft autosave survives;
- offline banner is exposed and Run/Test/Submit are disabled;
- authoring validation remains usable.
