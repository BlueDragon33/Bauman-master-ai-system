# PYTHON UX / ACCESSIBILITY ACCEPTANCE
P6 browser acceptance covers:
- desktop, tablet and 390×844 mobile without page-level horizontal overflow;
- keyboard editor Run shortcut and visible focusable controls;
- live status region and separated stdout/stderr/tests/evidence;
- explicit timeout/resource/output-limit messages;
- real in-flight Cancel semantics with stale-result quarantine;
- multi-tab draft conflict warning;
- honest offline execution unavailable state;
- authoring validation with canonical competency selection.

Pass/fail uses text/icon plus class, not color alone.
