# PYTHON ADJACENT-SUBJECT BOUNDARY

Python owns Python language semantics, Python-specific programming competency, language-specific debugging/testing evidence, and implementation bridges required to use Python in the target program.

| Boundary | Python may teach | Canonical theory owner |
|---|---|---|
| Algorithms | using Python to implement simple search/sort/data-structure examples | Algorithms: complexity proofs, advanced data structures, algorithm theory |
| Database | file/CSV/JSON work and later DB-client integration context | Database: relational model, SQL semantics, normalization, transactions, indexes, query planning |
| ML/Data | NumPy/Pandas operational prerequisites and implementation context | ML/Data Analysis: models, training, metrics, experiment theory |
| Software Engineering | Python packaging/module/test examples | Software Engineering: requirements, architecture/process, CI/CD, release, lifecycle theory |
| Math/Statistics | numeric operations required to implement a task | Math/Statistics: derivation, probability/statistical truth |
| Systems/Security | bounded file/process/network/security usage when needed | Systems/Security: OS, network and security theory |

The exact legacy routing is machine-readable in `PYTHON_LEGACY_LESSON_OWNERSHIP_MAP.json`. Routed lessons keep current IDs and remain available until the receiving owner/projection is ready; routing is not deletion.
