# PYTHON CONTENT PROVENANCE POLICY

Each canonical semantic claim should record authority and review state.

Authority levels:
- **L1_RUNTIME_SPEC** — official Python specification/documentation for supported version.
- **L2_RUNTIME_EVIDENCE** — deterministic execution/test evidence in controlled runtime.
- **L3_PROJECT_VALIDATED** — reviewed project-specific canonical example/test.
- **L4_CURATED_EXPLANATION** — reviewed teaching explanation.
- **L5_GENERATED_DRAFT** — AI/generated material; never canonical until promoted through authoring review.

Examples, counterexamples and coding tasks must declare hidden dependencies, expected behavior and version/package context where relevant.

AI may draft or coach, but cannot silently promote L5 content, assign official mastery, change official score, or expose hidden official tests.
