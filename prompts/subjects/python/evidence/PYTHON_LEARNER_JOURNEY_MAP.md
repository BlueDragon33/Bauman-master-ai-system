# PYTHON05 LEARNER JOURNEY MAP
Status: ACTIVE · testable

Python stays inside the shared Bauman subject shell. The primary learner surfaces are:
- Programming overview/roadmap;
- concept lesson;
- `code-lab.html`;
- review/practice;
- assessment preview;
- error-notebook/remediation links;
- progress owned by the shared platform.

## Pilot journeys
A. Beginner: concept → open Code Lab → inspect starter → Run with explicit stdin → modify → Run tests → review result.
B. Debugging: broken starter → Run → original stderr/traceback → hypothesis → edit → Run → public regression tests.
C. Assessment preview: edit → Run → public tests → Submit → evidence-only result. Submit does not directly write mastery or an official attempt; canonical learner-state integration remains authoritative.
D. Notebook/data: current runtime declares notebook execution unavailable. The UI states clean-container reproducibility and does not fake notebook/offline execution.
E. Author: open Task Authoring → configure prompt/runtime/tests/hints → Validate → sandbox Preview → export public record + secure author bundle → shared review/approval lifecycle.

## Evidence semantics
Run = ephemeral execution.
Run tests = governed public-test evidence.
Submit = assessment evidence envelope; it is not itself mastery truth.
Hidden tests never enter the learner bundle.
