# PYTHON EXECUTION CHEAT SHEET

For Work/Codex, do **not** load the entire prompt library by default.

Use:

`PYTHON_MASTER_PROMPT.md`

+ `STATUS.md`

+ one active `PYTHONxx` file

+ exact clauses selected by `PYTHON_CONSTITUTION_ROUTER.json`

+ current SHA/diff/evidence

+ impacted source/tests only.

## First execution

Run:

`PYTHON01_FORENSIC_BASELINE.md`

against current main.

Do not canonicalize PYTHON02 before PYTHON01 evidence.

## Default build sequence

`PYTHON01 → PYTHON02 → PYTHON03 → PYTHON04 → PYTHON05 → PYTHON06 → shared production release procedure`

## Key stop rules

Stop and escalate if:

- actual Python subject/runtime cannot be identified;
- learner code is not sandboxed;
- official assessment can duplicate/lose attempts;
- hidden tests/solutions leak;
- runtime/package version is ambiguous;
- a change requires redefining a global constitution owner.

## Token rule

`status → diff → owner → exact prompt → exact constitution clauses → targeted files/tests → broaden only if evidence requires`.
