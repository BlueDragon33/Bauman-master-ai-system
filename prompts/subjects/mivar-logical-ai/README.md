# 9. STEP 3 — MIVAR03

Open:

`MIVAR03_LOGICAL_REASONING_INFERENCE_ASSESSMENT.md`.

Goal:

**build logical reasoning and grading.**

Learner workflow:

`Formalize problem`

→ `define facts/entities`

→ `define rules`

→ `check domains/variables`

→ `choose inference direction`

→ `derive candidate facts`

→ `check conflicts`

→ `finish proof/inference chain`

→ `explain result`

→ `state limits / missing knowledge`.

Critical rule:

> A correct final answer is not enough if the inference chain uses an invalid rule, unbound variable, circular assumption, hidden fact or inconsistent knowledge state.

After PASS:

`MIVAR LOGICAL REASONING & ASSESSMENT CONTRACT LOCKED`.
