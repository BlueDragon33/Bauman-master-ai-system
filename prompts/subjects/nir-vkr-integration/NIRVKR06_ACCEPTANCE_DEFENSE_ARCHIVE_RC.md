# MISSION

Prove the integrated NIR/VKR system can preserve a correct research record from first topic to final archive.

# TEST MATRIX

## Project Identity
- duplicate project;
- wrong stage;
- stale project revision.

## Topic / Objective
- unpropagated title change;
- objective drift;
- old title in manuscript/slides.

## Artifacts
- missing mandatory artifact;
- wrong revision;
- duplicate artifact;
- stale artifact;
- broken dependency.

## Sources / Citations
- missing source;
- fabricated citation;
- citation mismatch;
- stale bibliography reference.

## Data / Code / Model
- code SHA mismatch;
- dataset version mismatch;
- config mismatch;
- model/checkpoint mismatch;
- inaccessible required artifact.

## Experiment / Result
- result without run;
- run without data/config;
- figure not reproducible;
- table from stale data;
- hidden manual result edit.

## Claim / Limitation
- unsupported claim;
- claim exceeds experiment;
- limitation omitted;
- negative result rewritten as success.

## Feedback
- blocking supervisor feedback unresolved;
- reviewer finding resolved without artifact change/evidence;
- feedback attached to wrong revision.

## Stage Gate
- green gate with missing evidence;
- institutional criterion invented;
- outdated deliverable accepted.

## Pre-diploma
Only actual evidence-derived requirements:
- readiness package incomplete;
- major experiment not complete;
- manuscript/artifact mismatch.

## VKR
- incomplete section coverage;
- final manuscript references obsolete artifact;
- figure/table numbering/link mismatch where checked.

## Defense
- slide claim absent from manuscript/evidence;
- demo uses different model/code/data;
- presentation uses stale metric;
- required artifact missing.

## Approval Integrity
- fabricated supervisor approval;
- fabricated reviewer feedback;
- fabricated signature;
- fabricated originality score;
- fabricated defense result.

## AI
AI must not:
- invent sources/results/comments;
- silently alter numerical result;
- mark gate approved;
- create fake signature/approval;
- state successful defense without evidence.

## Final Archive
Must identify exact final revisions of:
manuscript,
presentation,
code,
data refs,
models,
supplements,
required institutional files.
