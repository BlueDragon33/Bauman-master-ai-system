# 0. PURPOSE

This package governs the integrated research/capstone lifecycle connecting:

- scientific research work / НИР;
- research practice where applicable;
- project-technological practice where applicable;
- operational/pedagogical practice only if linked to the capstone workflow;
- pre-diploma practice;
- VKR / final qualification work;
- defense preparation;
- final evidence/portfolio handoff.

This system does **not** replace Research Methodology.

Research Methodology owns:
- how to formulate research questions;
- evidence quality;
- study design;
- scientific reasoning;
- reproducibility fundamentals.

NIR/VKR Integration owns:
- how one real research project progresses across semesters/stages;
- institutional milestones;
- supervisor/reviewer interactions;
- project/research artifacts;
- revision history;
- evidence completeness;
- research-to-thesis traceability;
- pre-diploma readiness;
- VKR manuscript/artifact readiness;
- defense readiness.

Canonical capstone chain:

`Research Context`
→ `Topic`
→ `Problem`
→ `Question / Objective`
→ `Supervisor / Approval Context`
→ `Research Plan`
→ `Literature / Evidence`
→ `Method / Experiment`
→ `Research Artifact`
→ `Interim Result`
→ `NIR Milestone`
→ `Practice Artifact`
→ `Pre-diploma Package`
→ `VKR Manuscript`
→ `Reproducibility Package`
→ `Review / Revision`
→ `Defense Package`
→ `Final Archive / Portfolio`.

Shared constitutions:
