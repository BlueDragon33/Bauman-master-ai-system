# DOCUMENT COMPLETENESS

# LITERATURE

Use RSW source/citation rules.

# EXPERIMENT

Use RSW/technical-subject experiment truth.

# RESULTS

No result may appear without provenance.

# CLAIMS

Claims cannot exceed evidence.

# NEGATIVE RESULTS

# REPRODUCIBILITY

Required level depends on actual project/institutional scope.

# FEEDBACK RESOLUTION

Blocking feedback prevents gate PASS until resolved/accepted according real authority.

# STAGE DELIVERABLE

Check mandatory artifacts only from institutional evidence.

# PRE-DIPLOMA READINESS

Potential dimensions:
- research scope stable;
- major experiments complete;
- manuscript substantially covered;
- artifacts reproducible;
- blocking review actions resolved.

Actual criteria from NIRVKR01 only.

# VKR READINESS

Potential:
- final manuscript;
- source integrity;
- code/data/model consistency;
- reviewer/supervisor requirements;
- defense materials;
- final archive.

Do not invent requirements.

# DEFENSE READINESS

Presentation/demo must match final artifact revisions.

# TEST-OF-TESTS

Known invalid cases must fail:
- report complete but experiment missing;
- figure copied from stale run;
- supervisor comment unresolved but gate green;
- defense slide claims metric not in final VKR;
- demo uses newer model than manuscript with no disclosure;
- final PDF title differs from approved topic revision.

# AI BOUNDARY

AI may coach readiness.
It cannot approve gates or fabricate institutional evidence.
