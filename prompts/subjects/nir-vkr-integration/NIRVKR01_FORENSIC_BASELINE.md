# NIRVKR01 — FORENSIC BASELINE
## Audit actual NIR / practice / pre-diploma / VKR workflow

Mode:

`AUDIT-ONLY · NO-REDESIGN · INSTITUTIONAL-EVIDENCE-FIRST`

# MISSION

Map the real Bauman/repository capstone workflow before defining canonical stages.

# DISCOVERY

Search for:
- НИР;
- scientific research work;
- research practice;
- project-technological practice;
- operational practice;
- pedagogical practice;
- pre-diploma;
- VKR / ВКР;
- thesis;
- final qualification work;
- supervisor;
- reviewer;
- department approval;
- task assignment;
- calendar plan;
- report;
- diary/log;
- originality/plagiarism;
- defense;
- presentation;
- demo;
- archive.

Do not assume all listed stages apply to the same capstone path.

# INSTITUTIONAL STAGE AUDIT

For each actual stage record:
- official name;
- semester/time;
- purpose;
- required artifacts;
- authority;
- acceptance criteria;
- output;
- next-stage dependency.

# TOPIC / TITLE AUDIT

Find:
topic proposal,
topic approval,
title revisions,
scope change,
language variants if required.

# SUPERVISOR / ADVISOR AUDIT

role,
feedback,

review frequency,
official vs informal comments.

# ASSIGNMENT / PLAN AUDIT

Find:
research assignment,
calendar plan,
tasks,
milestones,
dates,
expected outputs.

# NIR AUDIT

For each NIR stage:
- objectives;
- literature;
- method;
- experiment/analysis;
- result;
- report;
- assessment.

# PRACTICE AUDIT

Determine how each practice contributes to:
- technical artifact;
- research evidence;
- report;
- capstone readiness.

# MANUSCRIPT AUDIT

# CLAIM / EVIDENCE AUDIT

# FEEDBACK / REVIEW AUDIT

resolution status.

# ORIGINALITY / PLAGIARISM AUDIT

# PRE-DIPLOMA AUDIT

# FINAL ARCHIVE AUDIT

Find:

datasets,
models,
presentation,
supplements,
metadata.

# RSW BOUNDARY

Research Methodology owns scientific-method truth.

# PDM BOUNDARY

Project Design Management owns generic plan/change/risk coordination.

# SUBJECT OWNER BOUNDARY

Technical validity remains with the technical subject.

# ASSESSMENT AUDIT

Classify:
milestone,
report,
artifact,
readiness,
review,
defense.

# GRADER AUDIT

Check whether current logic:
- counts documents only;
- ignores provenance;
- ignores unresolved feedback;
- accepts stale artifacts.

# AI AUDIT

Check whether AI:
- fabricates citations/results;
- writes false supervisor approvals;
- invents reviewer comments;
- changes results;
- creates hidden ghost artifacts.

# DUPLICATE OWNER

Find duplicate:
research project registry,
artifact registry,
milestone tracker,
feedback store,
readiness engine,
final archive registry.

# LEGACY

KEEP / MIGRATE / RETIRE / UNKNOWN.

# RISK REGISTER

At minimum:
- invented institutional rule;
- disconnected NIR stages;
- stale topic title;
- result without provenance;
- manuscript/artifact mismatch;
- unresolved feedback;
- fake approval;
- final demo mismatch;
- incomplete archive.
