- platform kernel / Subject Factory;
- shared App Shell / Design System;
- generic mastery/evidence engine;
- generic content-governance lifecycle;
- generic code runtime when Python provider already exists;

ALG supplies prerequisites to Database, AI/ML, OS/Networks and Optimization, but those subjects own their domain-specific semantics.
