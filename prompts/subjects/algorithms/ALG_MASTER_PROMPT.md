# 10. NON-NEGOTIABLE ALGORITHMIC INVARIANTS

- ADT is distinct from concrete implementation.
- Correct output on examples is not sufficient proof of correctness.
- Big-O is not a stopwatch measurement.
- Worst/average/best/amortized meanings must not be conflated.
- Stable sorting is not identical to unstable sorting.
- Graph edge direction/weight semantics are explicit.
- Mutating vs non-mutating operations are explicit.
- Alternative correct algorithms must be accepted when task permits.
- Complexity constraints are assessed separately from functional correctness.
- AI cannot become canonical complexity/correctness authority.
- Visualization cannot redefine algorithm state.
