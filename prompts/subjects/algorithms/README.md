# 2. WHY THIS SUBJECT FOLLOWS PYTHON

Python provides implementation fluency.

Algorithms & Data Structures owns a different truth:

- abstract data types;
- algorithmic strategies;
- correctness;
- invariants;
- complexity;
- termination;
- trade-offs;
- data-structure operation semantics;
- transfer across implementation languages.

The subject may use Python for examples and labs, but Python syntax/runtime does not own algorithmic truth.

---

# 3. SUBJECT OWNERSHIP

ALG owns:

- asymptotic analysis;
- time/space complexity;
- recurrence reasoning where needed;
- correctness arguments;
- invariants;
- search/sort;

- dynamic programming;
- backtracking;
- graph traversal/paths;

- generic Mathematics;

- generic platform/runtime/release architecture.
