# PRIMARY SURFACES
User/task/context canvas; workflow/task model; information-requirement matrix; display/control critique; feedback/error analysis; accessibility audit; heuristic evaluation; cognitive walkthrough; usability-study protocol; observation timeline; performance/workload panel; before/after redesign; human-AI scenario; AI tutor; ergonomic report.

# UX CONTRACTS
- User/task canvas shows role, goal, frequency, criticality, context and constraints.
- Task flow shows steps, decisions, information, actions and errors.
- Findings link to task/evidence, not screenshot annotations alone.
- Accessibility audit groups keyboard, focus, semantics, visual, motion, input and errors.
- Before/after comparison uses completion/errors/time/accessibility/evidence, not screenshots alone.
- Human-AI view shows suggestion, uncertainty, human choice/override and result.
- HCI learning UI itself must model accessible interaction.

# AUTHORING
Use shared lifecycle. Authors can create task scenarios, interface critiques, accessibility cases, heuristic/walkthrough exercises, usability-study tasks, human-error cases, human-AI scenarios and redesign projects. Rubrics allow multiple valid redesigns.
