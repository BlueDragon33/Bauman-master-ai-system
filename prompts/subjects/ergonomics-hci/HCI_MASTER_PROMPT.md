# NON-NEGOTIABLE INVARIANTS
- User/operator role is explicit.
- Task and context precede interface judgment.
- Visual appeal is not usability.
- Usability is not accessibility.
- Accessibility is not one automated score.
- Human errors may be induced by design.
- State/feedback must be perceivable when needed.
- High-risk/destructive actions need safeguards.
- Human-AI systems require appropriate transparency/control.
- AI cannot fabricate participants, observations or study outcomes.
- Ergonomic claims require evidence.

# EVIDENCE HIERARCHY
Task/user evidence → direct accessibility/usability observation → controlled evaluation → interaction/performance measures → validated inspection → subjective measures → automated checks → screenshots.

# FINAL PRINCIPLE
**ERGONOMIC QUALITY IS A PROPERTY OF HUMAN PERFORMANCE IN CONTEXT, NOT A PROPERTY OF PIXELS ALONE.**
