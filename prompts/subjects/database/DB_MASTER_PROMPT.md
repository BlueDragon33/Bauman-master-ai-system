# 6. NON-NEGOTIABLE DATABASE INVARIANTS

- A table is not “just a spreadsheet”.
- Primary key semantics are not UI row numbering.
- SQL result equality on one dataset does not prove semantic equivalence.
- SQL tables/results are unordered unless ORDER BY semantics guarantee order.
- NULL is not zero/empty string/false.
- Three-valued logic must be respected.
- COUNT(*) and COUNT(column) are not always equivalent.
- INNER/LEFT/RIGHT/FULL joins are not interchangeable.
- Constraints are part of database truth.
- Normalization is not “split tables until small”.
- Index existence does not guarantee index usage.
- Query plan is engine/version/config dependent.
- Transactions/isolation claims must name the isolation model/phenomenon.
- Learner SQL must never execute with unrestricted production credentials.
- AI is not the official database grader/mastery owner.
