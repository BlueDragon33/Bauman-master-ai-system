# 1. WHY DATABASE COMES AFTER PYTHON + ALGORITHMS

Python provides implementation fluency.

Algorithms & Data Structures provides:

- search;
- trees;
- hashing;
- complexity;
- graphs;
- reasoning about trade-offs.

Database Systems builds on both but owns a different body of truth:

- data modeling;
- relational algebra;
- SQL semantics;
- keys/constraints;
- normalization;
- query processing;
- indexing;
- transactions;
- isolation;
- concurrency;
- recovery;
- storage/query-planner concepts.

Database must not become:

- “SQL syntax only”;
- “Python ORM only”;
- “B-tree animation only”;
- “copy queries until output looks right”.
